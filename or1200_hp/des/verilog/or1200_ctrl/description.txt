Functional Overview:
Module `or1200_ctrl` decodes instructions and generates control signals for ALU, LSU, register write-back, branching, and pipeline control.

The file header states: “Majority of instruction decoding is performed here.”
This module is the central decode/control block of the processor. It interprets fetched instructions and generates control signals that drive:
- register file access
- immediate generation
- ALU/compare/shift operation selection
- branch handling
- load/store unit control
- multicycle operation control
- special-purpose register access
- write-back selection
- exception-related sideband control

Description:
This module is the main instruction decoding and pipeline control unit of OR1200. It is responsible for decoding the fetch-level input instruction if_insn into control signals such as register access, ALU/MAC/LSU/branch/compare/writeback, and maintaining pipeline registers of instructions and several control fields between the ID, EX, and WB levels. The module uses the rising edge of clk to update the timing status. When rst is reset, the instruction and control registers at all levels are initialized to specific NOP codes; flushpipe will also force the relevant pipeline levels to be cleared to NOP, so reset and flushing take precedence over normal advancement. The freeze signals id_freeze, ex_freeze, and wb_freeze respectively control whether the corresponding level maintains the current state.

In terms of combined decoding, the module directly generates the register file read address and read enable semantics from if_insn: rf_addra=if_insn[20:16], rf_addrb=if_insn[15:11], rf_rda/ rf_rdb respectively come from the high bits of the instruction and are used to indicate whether the corresponding source register port is used by the instruction. sel_a and sel_b perform forward selection based on the current ID instruction source register number, EX/WB level write-back destination register number and valid write-back flag; among them, for sel_b, the immediate data selection sel_imm has the highest priority. Once the instruction belongs to the immediate data type, sel_b directly selects the immediate data instead of the register or forward data. simm is obtained by sign extension or zero extension of the lower 16 bits of id_insn. The specific extension method is determined by the instruction type. branch_addrofs is obtained by sign extension of ex_insn[25:0], and lsu_addrofs uses different immediate field splicing methods for store and load instructions according to the LSU operation type to generate effective address offsets.

In terms of timing decoding, the module latches if_insn to id_insn, id_insn to ex_insn, and ex_insn to wb_insn. In terms of priority, rst and flushpipe will clear these pipeline registers; for ex-level control registers, when the "ID is frozen but EX is not frozen" situation occurs, NOP will be inserted into EX to prevent old instructions from being executed repeatedly by mistake. rf_addrw is generated at the EX level and takes the destination register field id_insn[25:21] by default, but for link branches such as JR/BAL, it is forced to write to the link register r9; wb_rfaddrw saves another beat at the WB level for forward judgment. spr_addrimm is also generated from the ID instruction on the clock edge, where mfspr uses bits[15:0] and mtspr concatenates bits[25:21] with bits[10:0]. multicycle, sel_imm and imm_signextend are decoded by the current ID instruction type, where multicycle is mainly effective for specific ALU multi-cycle operations.

Function control output includes: alu_op, mac_op, shrink_op, comp_op, lsu_op, branch_op, rfwb_op, cust5_op, cust5_limm, sig_syscall, sig_trap, except_illegal, rfe, etc. They are generated based on the instruction main opcode and some subfields, and are registered at the required pipeline level. except_illegal is registered at the EX level and will output 0 only for explicitly listed OR1200 supported instructions, and 1 for unrecognized or unimplemented instructions. id_macrc_op is used to identify the MAC result read operation formed by movhi+special bit combination at the ID level, and ex_macrc_op is its EX-level timing version. rfe is 1 on pre-branch operations or when formal branch_op is RFE, used to drive the exception return path.

For branch and delay slot control, the module gives branch_op and no_more_dslot. no_more_dslot is set when it is detected that the branch has been established and the current ID instruction is not empty, or the current branch type is RFE, to notify the instruction fetch/PC logic not to continue normal delay slot processing. id_void and ex_void detect specific NOP codes to indicate that the corresponding pipeline level is a no-op. force_dslot_fetch is hardwired to 0 in the current implementation, so no additional pull delay slot instructions are forced. On the whole, this module encodes all the main control semantics required by an OR1200 instruction in the pipeline, and ensures that these control signals are consistent with the instruction flow through reset, flush and freeze rules.

Module name:
module or1200_ctrl(
    // Clock and reset
    input clk,
    input rst,

    // Internal i/f
    input id_freeze,
    input ex_freeze,
    input wb_freeze,
    input flushpipe,
    input [31:0] if_insn,
    output [31:0] ex_insn,
    output [2:0] branch_op,
    input branch_taken,
    output [4:0] rf_addra,
    output [4:0] rf_addrb,
    output rf_rda,
    output rf_rdb,
    output [3:0] alu_op,
    output [1:0] mac_op,
    output [1:0] shrot_op,
    output [3:0] comp_op,
    output [4:0] rf_addrw,
    output [2:0] rfwb_op,
    output [31:0] wb_insn,
    output [31:0] simm,
    output [31:2] branch_addrofs,
    output [31:0] lsu_addrofs,
    output [1:0] sel_a,
    output [1:0] sel_b,
    output [3:0] lsu_op,
    output [4:0] cust5_op,
    output [5:0] cust5_limm,
    output [1:0] multicycle,
    output [15:0] spr_addrimm,
    input wbforw_valid,
    input du_hwbkpt,
    output sig_syscall,
    output sig_trap,
    output force_dslot_fetch,
    output no_more_dslot,
    output ex_void,
    output id_macrc_op,
    output ex_macrc_op,
    output rfe,
    output except_illegal
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - id_freeze: Freeze control for the decode stage.
    - ex_freeze: Freeze control for the execute stage.
    - wb_freeze: Freeze control for the writeback stage.
    - flushpipe: Pipeline flush request.
    - if_insn[31:0]: Instruction word presented to the decode stage.
    - branch_taken: Indicates whether the current branch decision is taken.
    - wbforw_valid: Indicates that the writeback-forwarding path carries valid data.
    - du_hwbkpt: Hardware-breakpoint request generated by the debug unit.
Output port:
    - ex_insn[31:0]: Instruction word in the execute stage.
    - branch_op[2:0]: Encoded branch/jump operation selector.
    - rf_addrw[4:0]: Register-file write address.
    - rf_addra[4:0]: Register-file read address for source port A.
    - rf_addrb[4:0]: Register-file read address for source port B.
    - rf_rda: Source-A register-read enable from the control path.
    - rf_rdb: Source-B register-read enable from the control path.
    - alu_op[3:0]: Major ALU operation selector.
    - mac_op[1:0]: Encoded MAC operation selector.
    - shrot_op[1:0]: Shift/rotate sub-operation selector.
    - rfwb_op[2:0]: Encoded writeback-source selector and valid bit.
    - wb_insn[31:0]: Instruction word in the writeback stage.
    - simm[31:0]: Expanded immediate operand supplied to execute-stage muxing.
    - branch_addrofs[31:2]: Branch target offset produced by the decode/control path.
    - lsu_addrofs[31:0]: Load/store address offset generated by the control path.
    - sel_a[1:0]: Source selector for execute-stage operand A.
    - sel_b[1:0]: Source selector for execute-stage operand B.
    - lsu_op[3:0]: Encoded load/store operation selector.
    - comp_op[3:0]: Compare sub-operation selector.
    - multicycle[1:0]: Multi-cycle operation control value used by the freeze logic.
    - cust5_op[4:0]: Minor opcode for l.cust5 custom operations.
    - cust5_limm[5:0]: Immediate field used by l.cust5 custom operations.
    - spr_addrimm[15:0]: Immediate SPR address field generated by the decode/control logic.
    - sig_syscall: Raw system-call exception source.
    - sig_trap: Raw trap exception source.
    - force_dslot_fetch: Control that forces fetching of a branch delay-slot instruction.
    - no_more_dslot: Indicates that no further delay-slot instruction should be executed.
    - ex_void: Indicates that the execute stage currently holds a void/NOP instruction.
    - id_macrc_op: Decode-stage indication that the current instruction reads the MAC result.
    - ex_macrc_op: Execute-stage MAC-result-read indication.
    - rfe: Exception-return control indication.
    - except_illegal: Illegal-instruction exception indication exported to exception control.
