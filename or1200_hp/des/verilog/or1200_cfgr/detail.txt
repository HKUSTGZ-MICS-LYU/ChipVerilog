1. Functional Requirements
1.1 Read-only decode
The module shall be purely combinational and shall decode spr_addr to produce the requested configuration word.
No write path exists in this module.

1.2 Address decode scope
If OR1200_SYS_FULL_DECODE is enabled, the module shall only respond when spr_addr[31:4] is zero.
Otherwise it directly decodes spr_addr[3:0].

1.3 Required implemented registers when OR1200_CFGR_IMPLEMENTED is defined
The RTL returns the following architectural words:
- VR: Version Register
- UPR: Unit Present Register
- CPUCFGR: CPU Configuration Register
- DMMUCFGR: Data MMU Configuration Register
- IMMUCFGR: Instruction MMU Configuration Register
- DCCFGR: Data Cache Configuration Register
- ICCFGR: Instruction Cache Configuration Register
- DCFGR: Debug Configuration Register

For each register, individual bitfields are assigned from constants in or1200_defines.v.

1.4 Minimum implemented registers when OR1200_CFGR_IMPLEMENTED is not defined
The fallback implementation still supports:
- VR
- UPR
All other locations return 0.

1.5 Default response
For unknown addresses, the module shall return 32'h0000_0000.

2. Register Semantics
2.1 Version Register (VR)
The module shall assemble the VR output from the revision, reserved, configuration, and version fields:
- OR1200_VR_REV
- OR1200_VR_RES1
- OR1200_VR_CFG
- OR1200_VR_VER

2.2 Unit Present Register (UPR)
The module shall report which major units are implemented, including fields such as:
- UP (UPR present)
- DCP / ICP (data and instruction cache presence)
- DMP / IMP (data and instruction MMU presence)
- MP (MAC/multiplier presence)
- DUP (debug unit presence)
- PCUP / PMP / PICP / TTP
- CUP and reserved fields

2.3 CPU and subsystem configuration registers
The module shall provide OR1200 implementation constants describing CPU arithmetic capabilities, MMU topology, and cache organization.

3. Implementation Notes
- The RTL is a single always @(spr_addr) combinational decoder.
- Register fields are not computed dynamically; they are assembled from compile-time constants.
- The block does not depend on the pipeline state, clock, or reset.
