
Module `or1200_alu` performs OR1200 execute-stage arithmetic, logic, shift, compare, and flag-generation operations.

This module is the main arithmetic, logic, compare, shift/rotate, and selected custom-instruction execution block of the OR1200 integer datapath. It accepts two 32-bit operands plus a multiplier/MAC result path and produces:
- the 32-bit execution result
- the forwarded compare flag value and flag write-enable
- the forwarded carry value and carry write-enable

At project level, this ALU is part of the “functional core” that is hyper pipelined on RTL. The PDF states that “the functional pipelined RISC processor can be hyper pipelined to generate CMF individual RISC processors” and that the “resulting hyper pipelined OR1200 core has the same inputs and outputs plus the new clk_i_cml_* clocks.” This module therefore defines the original functional behavior that must be preserved after retiming.

Description:

The module performs OR1200 execute-stage arithmetic, logic, shift, compare, and flag-generation operations.

- It is important to notice, that the individual core does not store its values when switched off.
- It always restarts with the reset values, respectively the reset sequence if the core is a processor.
- If a core is switched off, the clocks can also be gated to reduce activity on the clock line.


This module is the OR1200's integer ALU combinatorial execution unit and contains no clock or reset registers, with all outputs determined by the current combination of inputs. The module receives two main operands a, b, and the result mult_mac_result from the multiplication/MAC unit; selects specific operations based on alu_op, shrot_op, comp_op and custom instruction fields cust5_op/cust5_limm, and outputs the final result result. At the same time, it also generates the forward value of the flag bit and carry bit in the status register and its write enable, which is used by the upper layer to update SR[FLAG] and SR[CY] when needed.

The generation rules of result are completely determined by alu_op. The module supports addition, subtraction, AND, OR, XOR, immediate passthrough, movhi, high-bit load, shift/rotate, comparison, conditional move, multiplication/division result transparent transmission, as well as FF1 and several l.cust5 example instructions. FF1 returns the first bit position in a that is 1 starting from the lowest bit, ranging from 1 to 32; if a is 0, 0 is returned. MOVHI does not perform "immediate left shift by 16 bits" when macrc_op is 1, but returns mult_mac_result directly; therefore macrc_op has priority over the MOVHI path. Conditional move CMOV uses the input flag as a condition. When the flag is 1, it outputs a, otherwise it outputs b. The shift/rotation logic is further subdivided by shrot_op: logical left shift and logical right shift are supported. Optional implementation supports circular right shift. The default branch is arithmetic right shift. The comparison logic first transforms the sign bit according to comp_op[3], thereby reusing the same comparison network to complete signed/unsigned comparison, and then selects equal to, not equal to, greater than, greater than or equal to, less than, less than or equal to comp_op[2:0], and reflects the result on flagforw.

The module independently generates "new value" and "write enable" for the flag bit and carry bit respectively. flagforw is equal to the comparison result when comparing instructions; if the additional flag modification option is enabled, ADD, ADDC and AND will also write whether the result is zero to flagforw, and raise flag_we at the same time. Otherwise only comparison instructions will write FLAG. Similarly, if carry support is enabled in the implementation, ADD outputs cy_sum, ADDC outputs cy_csum, and pulls cy_we high on the corresponding instruction; other instructions have cyforw 0 and cy_we 0. Addition and addition with carry obtain the result and carry respectively by extending the adder by one bit, so there are no additional timing states. The custom l.cust5 example implements three types of operations: byte insertion, bit setting and bit clearing; a missed cust5_op retains the original value of a by default. The entire module has no internal latches or pipeline registers, all behavior is pure combinational logic, and the output changes instantly with the input.

module or1200_alu(
    input [31:0] a,
    input [31:0] b,
    input [31:0] mult_mac_result,
    input macrc_op,
    input [3:0] alu_op,
    input [1:0] shrot_op,
    input [3:0] comp_op,
    input [4:0] cust5_op,
    input [5:0] cust5_limm,
    output [31:0] result,
    output flagforw,
    output flag_we,
    output cyforw,
    output cy_we,
    input carry,
    input flag
);

Input ports:
    - a[31:0]: Primary operand A for the datapath operation.
    - b[31:0]: Primary operand B for the datapath operation.
    - mult_mac_result[31:0]: Result returned from the multiplier/MAC datapath.
    - macrc_op: Selects the MAC-result return path used by MOVHI/MACRC handling.
    - alu_op[3:0]: Major ALU operation selector.
    - shrot_op[1:0]: Shift/rotate sub-operation selector.
    - comp_op[3:0]: Compare sub-operation selector.
    - cust5_op[4:0]: Minor opcode for l.cust5 custom operations.
    - cust5_limm[5:0]: Immediate field used by l.cust5 custom operations.
    - carry: Incoming carry flag from the status-register path.
    - flag: Incoming flag bit used by compare and conditional-move logic.
Output port:
    - result[31:0]: Final result produced by this module.
    - flagforw: Forwarded next value for the SR flag bit.
    - flag_we: Write-enable for the SR flag bit.
    - cyforw: Forwarded next value for the SR carry bit.
    - cy_we: Write-enable for the SR carry bit.
Internal reg/wire signals:
    reg [31:0] result: Result.
    reg [31:0] shifted_rotated: Shifted rotated.
    reg [31:0] result_cust5: Result cust 5.
    reg flagforw: Forwarded condition-flag value.
    reg flagcomp: Flagcomp.
    reg flag_we: Flag write-enable.
    reg cy_we: Carry write-enable.
    wire [31:0] comp_a: Compare A.
    wire [31:0] comp_b: Compare B.
    wire a_eq_b: A eq B.
    wire a_lt_b: A lt B.
    wire [31:0] result_sum: Result sum.
    wire [31:0] result_csum: Result csum.
    wire cy_csum: Carry csum.
    wire [31:0] result_and: Result and.
    wire cy_sum: Carry sum.
    reg cyforw: Forwarded carry-flag value.
    wire [32:0] cy_sum_result_sum: Carry sum result sum.
    wire [32:0] cy_csum_result_csum: Carry csum result csum.
