
Module `or1200_ic_top` integrates instruction-cache datapath/control between fetch logic and the external memory interface.

This module is the complete instruction-cache top level. It integrates the instruction-cache FSM, data RAM, and tag RAM, and presents a unified interface between the CPU-side instruction request channel and the external instruction BIU.

Description:

The module integrates instruction-cache datapath/control between fetch logic and the external memory interface.


This module is the top layer of the instruction cache and is responsible for connecting the instruction fetch request on the CPU/QMEM side with the external instruction bus BIU, Cache data RAM, Cache tag RAM and instruction cache state machine to form a complete instruction cache access path. The module supports both hit/miss processing when the Cache is enabled and bypass access when the Cache is turned off. It also provides tag invalidation capabilities based on SPR write operations.

In terms of interface semantics, `icqmem_*` is an internal request from the upstream fetch path; `icbiu_*` is an access sent to the external bus interface; `spr_cs` and `spr_write` are used together to trigger cache line tag invalidation. `ic_en` is the master switch: when it is 0, this module directly bypasses internal requests to the external BIU without going through Cache hit judgment; when it is 1, the address, hit comparison, data return and backfill are all completed by the Cache structure and `or1200_ic_fsm`.

Combinatorially, `icbiu_adr_o` always comes from the currently valid `ic_addr`. When the state machine is performing a bus read or backfill, `ic_addr` selects `saved_addr`; otherwise, the input fetch address `icqmem_adr_i` is used directly. When the Cache is turned on, `icbiu_cyc_o`, `icbiu_stb_o`, `icbiu_sel_o` and `icbiu_cab_o` are controlled by the `biu_read` and `burst` of the state machine; when the Cache is turned off, the above signals directly transmit internal requests transparently. This module never initiates a write operation to the external command bus, so `icbiu_we_o` is always 0 and `icbiu_dat_o` is fixed to 0. For the upstream, `icqmem_ack_o` consists of "first hit response" or "miss first word return response" when the Cache is enabled. When the Cache is closed, it is directly equal to the response of the external BIU; `icqmem_err_o` is only generated by the first word miss error when the Cache is enabled, otherwise the external error is passed directly. `icqmem_rty_o` is represented by `~ack & ~err`, indicating that as long as it has not terminated successfully or failed, it will continue to be treated as waiting.

In terms of tag comparison, the module splits the Tag RAM output into the valid bit `tag_v` and the tag field `tag`, and then compares the four segments of tag bits with the high-order address corresponding to `saved_addr`. As long as any segment does not match or the valid bit is invalid, `tagcomp_miss` is set. This is equivalent to comparing the entire tag, but split into smaller bit segments. When `icfsm_first_miss_ack` or Cache is closed, `icqmem_dat_o` directly uses external return data; in other hit scenarios, the data is fetched from Cache data RAM `from_icram`.

In terms of timing, this module itself has no explicit local status register. Except for the BIST cascade signal, all timing status is maintained by the submodules `or1200_ic_fsm`, `or1200_ic_ram` and `or1200_ic_tag` on the rising edge of `clk`, and reset `rst` is distributed to these submodules synchronously. Tag invalidation is triggered by `spr_cs & spr_write`: at this time `ictag_we` is forced high, the write address uses the index given in `spr_dat_i`, and the valid bit `ictag_v` of the write is set to 0, thereby invalidating the corresponding row; during normal backfill, the tag write enable is generated by the state machine, and the write address and tag are determined by the current backfill address.

Therefore, the key behaviors of this module can be summarized as follows: when the Cache is opened, it is responsible for hit comparison, first-word fast response, full row backfilling after a miss, and label updating; when the Cache is closed, it is unconditionally bypassed; SPR write operations have the highest priority for label invalidation and directly override the normal label address and valid bit control.

module or1200_ic_top(
    // Rst, clk and clock control
    input clk,
    input rst,

    // External i/f
    output [31:0] icbiu_dat_o,
    output [31:0] icbiu_adr_o,
    output icbiu_cyc_o,
    output icbiu_stb_o,
    output icbiu_we_o,
    output [3:0] icbiu_sel_o,
    output icbiu_cab_o,
    input [31:0] icbiu_dat_i,
    input icbiu_ack_i,
    input icbiu_err_i,

    // Internal i/f
    input ic_en,
    input [31:0] icqmem_adr_i,
    input icqmem_cycstb_i,
    input icqmem_ci_i,
    input [3:0] icqmem_sel_i,
    input [3:0] icqmem_tag_i,
    output [31:0] icqmem_dat_o,
    output icqmem_ack_o,
    output icqmem_rty_o,
    output icqmem_err_o,
    output [3:0] icqmem_tag_o,

`ifdef OR1200_BIST
    // RAM BIST
    input mbist_si_i,
    output mbist_so_o,
    input [`OR1200_MBIST_CTRL_WIDTH - 1:0] mbist_ctrl_i,
`endif

    // SPRs
    input spr_cs,
    input spr_write,
    input [31:0] spr_dat_i
);

    - ic_en: Instruction-cache enable control.
    - icqmem_adr_i[31:0]: Address bus for the instruction-cache/QMEM interface.

    - icqmem_ci_i: Cache-inhibit attribute for the instruction-cache/QMEM interface.
    - icqmem_sel_i[3:0]: Byte-lane select for the instruction-cache/QMEM interface.
    - icqmem_tag_i[3:0]: Tag field carried on the instruction-cache/QMEM interface.
