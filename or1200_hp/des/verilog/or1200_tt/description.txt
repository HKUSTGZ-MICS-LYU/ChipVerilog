
Module `or1200_tt` implements the OR1200 tick timer counter, match logic, and timer-interrupt generation.

This module implements the OR1K Tick Timer. It contains the Tick Timer Mode Register (TTMR) and Tick Timer Count Register (TTCR), generates a periodic or one-shot interrupt according to mode, and supports debug-unit stall interaction.

Description:

The module implements the OR1200 tick timer counter, match logic, and timer-interrupt generation.


This module implements Tick Timer (TT) and provides a programmable counter and mode register for generating periodic or one-time timed interrupts. Software can access the TT mode register `TTMR` and the counting register `TTCR` through SPR. The module determines whether to restart counting, stop counting and set the interrupt pending bit based on the mode field, threshold value and current count value.

When `OR1200_TT_IMPLEMENTED` is enabled, the module contains two main timing registers: `ttmr` and `ttcr`, both updated on the rising edge of `clk` with an asynchronous high reset `rst`. `ttmr_sel` and `ttcr_sel` are decoded according to `spr_cs` and `spr_addr`, corresponding to hitting TTMR or TTCR. After reset, `ttmr` is cleared to 32'b0 when TTMR is implemented; when TTMR storage is not implemented, it is tied to a constant value ({2'b11,30'b0}), and `ttcr` is cleared. If the software writes TTMR, the entire `ttmr` is directly loaded with `spr_dat_i`; otherwise, if TTMR[IE] (ttmr[29]) is set, TTMR[IP] (ttmr[28]) is updated as ttmr[28] <= ttmr[28] | (match & ttmr[29]). So once the count hits the threshold and interrupts are enabled, the pending bit is set and remains set until software overwrites TTMR. The update priority of `ttcr` is: reset is the highest, followed by `restart` to clear the counter, then software writes TTCR, and finally increments by 1 at `!stop`.

In terms of combinational logic, `match` is established when the threshold field `TP` of `TTMR` is equal to `ttcr[27:0]`. `restart` is only true when `match` and the mode field `M==2'b01`, indicating automatic reload/restart mode; `stop` is true in three scenarios: hit and mode is 2'b10, mode is 2'b00 (disabled) or debug shutdown `du_stall`. Therefore debug shutdown has the same priority as "stop counting" and freezes the counter increment. The interrupt output `intr` is directly equal to `ttmr[IP]`, so the timer does not directly pull `intr` high at the moment of `match`, but outputs it after being latched by the suspend bit.

The SPR read interface is combinational logic: accessing the TTMR address returns `ttmr`, accessing the TTCR address returns `ttcr`, and other addresses return 0. If the Tick Timer is not enabled, the implementation degrades to constant zero: `intr=0`, `spr_dat_o=0`. This module has no additional state machine and its behavior is entirely determined by the comparison between the `TTMR` mode field and the current count/threshold. The update priority is clearly as follows: for `TTMR`, software writing takes precedence over auto-set suspend; for `TTCR`, restart takes precedence over software writing, and software writing takes precedence over natural counting.

module or1200_tt(
    // RISC Internal Interface
    input clk,
    input rst,
    input du_stall,
    input spr_cs,
    input spr_write,
    input [31:0] spr_addr,
    input [31:0] spr_dat_i,
    output [31:0] spr_dat_o,
    output intr
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - du_stall: Debug-unit stall request into the pipeline.
    - spr_cs: SPR chip-select for this module.
    - spr_write: SPR write strobe for this module.
    - spr_addr[31:0]: SPR address used for register decode.
    - spr_dat_i[31:0]: Write data from the SPR/control path.
Output port:
    - spr_dat_o[31:0]: Read data returned on the SPR bus.
    - intr: Combined interrupt request output.
Internal reg/wire signals:
    reg [31:0] ttmr: Tick-timer mode register.
    wire [31:0] ttmr: Tick-timer mode register.
    reg [31:0] ttcr: Tick-timer count register.
    wire [31:0] ttcr: Tick-timer count register.
    wire ttmr_sel: Tick-timer mode register select.
    wire ttcr_sel: Tick-timer count register select.
    wire match: Timer-match flag.
    wire restart: Counter-restart flag.
    wire stop: Counter-stop flag.
    reg [31:0] spr_dat_o: SPR data output.
