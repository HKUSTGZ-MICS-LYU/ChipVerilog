
Module `or1200_wb_biu` adapts OR1200 data-side load/store traffic to Wishbone bus transactions and response handling.

This module implements the WISHBONE Bus Interface Unit. The source file describes it as “Implements WISHBONE interface.” It converts between the OR1200 internal BIU request/response protocol and the external WISHBONE bus protocol, while supporting configurable clock-rate division, optional registered inputs/outputs, retry handling, and graceful abort termination.

Description:

The module adapts OR1200 data-side load/store traffic to Wishbone bus transactions and response handling.


This module implements the bridge between the OR1200 internal BIU and the external Wishbone bus. It is responsible for converting internal `biu_*` requests into Wishbone `cyc/stb/we/sel/adr/dat` signals, and converting Wishbone's `ack/err/rty/dat` returns into CPU-visible completion, error and read data. At the same time, the module supports optional input/output registration, optional bus clock frequency division synchronization, retry waiting, and graceful ending of canceled transactions.

From the interface semantics, `biu_*` is a single or burst access request inside the processor, and `wb_*` is an external Wishbone port. `clmode` indicates the frequency division mode of the external WB clock relative to the RISC clock. `valid_div` is cycle counted in the RISC clock domain and is used to compress the long pulse `long_ack_o/long_err_o` from the WB side into a single beat of `biu_ack_o/biu_err_o` at the appropriate RISC moment. So when the WB is operating at 1/2 or 1/4 the RISC frequency, the return handshake is not internally missampled multiple times.

The timing register mainly includes `valid_div`, optional registered output signal `wb_adr_o/wb_cyc_o/wb_stb_o/wb_we_o/wb_sel_o/wb_dat_o`, optional registered input `biu_dat_o/long_ack_o/long_err_o`, and abort holding bit `aborted_r`, optional retry counter `retry_cntr`, and optional burst counter `burst_len`. These registers are updated on the rising edge of `clk` or `wb_clk_i` respectively, and each has a corresponding asynchronous reset `rst` or `wb_rst_i`. Among them, the address and output data are only updated when "there is currently a new request, no ACK, no aborted, and the previous request is not in stb hold"; read data is only sampled at `wb_ack_i`; `retry_cntr` is filled up at `wb_rty_i` and decrements beat by beat; `burst_len` is loaded to 3 during non-burst and decremented during burst ACK, used to generate Wishbone B3 `cti`.

In terms of handshake conversion, `biu_ack_o` and `biu_err_o` are not simply directly connected, but are obtained from `long_ack_o/long_err_o` through frequency division mode gating. If registered input is defined, `long_ack_o/long_err_o` latches `wb_ack_i/wb_err_i` on the WB clock and masks `aborted`; otherwise, use `wb_ack_i/wb_err_i` and `~aborted_r` directly. This ensures that even if the external bus returns aborted after the internal request has been aborted, expired responses will still be swallowed correctly with `aborted_r`.

Retrying and canceling transactions are key boundary behaviors of this module. `retry` is set immediately after receiving `wb_rty_i` and remains 1 until the `retry_cntr` countdown ends, thus temporarily blocking the issuance of new `wb_cyc_o`. `aborted` is established when "there is still `stb` on the WB side, but the internal `biu_cyc_i & biu_stb_i` has been revoked, and the current transaction has not received ACK/ERR", indicating that the transaction has been abandoned internally, but the external bus has not officially ended. `aborted_r` will keep this state until `wb_ack_i` or `wb_err_i` is actually received, so that the aborted termination is not propagated back internally.

The priority of Wishbone output is also very clear. `wb_cyc_o` is driven by `biu_cyc_i` under normal circumstances and can be suspended by `retry`; if it is an unfinished canceled transaction, `aborted & ~wb_ack_i` will force `cyc` to continue until the official end is given externally. `wb_stb_o` is pulled high when there is an internal request and is not blocked by `retry`, and will also remain during aborted. `wb_we_o` takes `biu_we_i` during normal requests, and keeps the original writing direction unchanged during aborted. `wb_sel_o` and `wb_dat_o` correspond to internal byte strobe and write data respectively. If CAB/B3 is enabled, `wb_cab_o` transparently transmits the internal burst indication, `wb_cti_o` outputs the incremental burst code in the middle beat of the burst, and outputs the end-of-burst in the last beat. `wb_bte_o` is fixed to 4-beat wrap burst.

Therefore, this module is not a simple wire bridge, but a Wishbone BIU that fully handles cross-clock/division synchronization, read and write registers, retry delays, canceled transaction aftermath, and optional burst transfers. Reset always gives priority to clearing all registered states; during operation, the division priority is roughly as follows: ACK/ERR termination gives priority to clearing the aborted/retry state, then handles new request loading, and then the combinational logic determines the retention and gating of external `cyc/stb/we`.

module or1200_wb_biu(
    // RISC clock, reset and clock control
    input clk,
    input rst,
    input [1:0] clmode,

    // WISHBONE interface
    input wb_clk_i,
    input wb_rst_i,
    input wb_ack_i,
    input wb_err_i,
    input wb_rty_i,
    input [31:0] wb_dat_i,
    output wb_cyc_o,
    output [31:0] wb_adr_o,
    output wb_stb_o,
    output wb_we_o,
    output [3:0] wb_sel_o,
    output [31:0] wb_dat_o,
`ifdef OR1200_WB_CAB
    output wb_cab_o,
`endif
`ifdef OR1200_WB_B3
    output [2:0] wb_cti_o,
    output [1:0] wb_bte_o,
`endif

    // Internal RISC bus
    input [31:0] biu_dat_i,
    input [31:0] biu_adr_i,
    input biu_cyc_i,
    input biu_stb_i,
    input biu_we_i,
    input [3:0] biu_sel_i,
    input biu_cab_i,
    output [31:0] biu_dat_o,
    output biu_ack_o,
    output biu_err_o
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - clmode[1:0]: Clock-division mode that defines the WB-to-RISC timing ratio.
    - wb_clk_i: Wishbone-side clock input used by the external bus domain.
    - wb_rst_i: Wishbone-side reset input used by the external bus domain.
    - wb_ack_i: Acknowledge/transfer-complete indication for the external Wishbone bus.
    - wb_err_i: Error termination indication for the external Wishbone bus.
    - wb_rty_i: Retry/wait indication for the external Wishbone bus.
    - wb_dat_i[31:0]: Data bus for the external Wishbone bus.
    - biu_dat_i[31:0]: Data bus for the internal BIU interface.
    - biu_adr_i[31:0]: Address bus for the internal BIU interface.
    - biu_cyc_i: Cycle-valid request for the internal BIU interface.
    - biu_stb_i: Strobe/request-valid qualifier for the internal BIU interface.
    - biu_we_i: Write-enable / write-versus-read qualifier for the internal BIU interface.
    - biu_cab_i: Consecutive-address burst indication for the internal BIU interface.
    - biu_sel_i[3:0]: Byte-lane select for the internal BIU interface.
Output port:
    - wb_cyc_o: Cycle-valid request for the external Wishbone bus.
    - wb_adr_o[31:0]: Address bus for the external Wishbone bus.
    - wb_stb_o: Strobe/request-valid qualifier for the external Wishbone bus.
    - wb_we_o: Write-enable / write-versus-read qualifier for the external Wishbone bus.
    - wb_sel_o[3:0]: Byte-lane select for the external Wishbone bus.
    - wb_dat_o[31:0]: Data bus for the external Wishbone bus.
    - wb_cab_o: Consecutive-address burst indication for the external Wishbone bus. Present only when `OR1200_WB_CAB` is enabled.
    - wb_cti_o[2:0]: Cycle-type identifier for the external Wishbone bus. Present only when `OR1200_WB_B3` is enabled.
    - wb_bte_o[1:0]: Burst-type extension for the external Wishbone bus. Present only when `OR1200_WB_B3` is enabled.
    - biu_dat_o[31:0]: Data bus for the internal BIU interface.
    - biu_ack_o: Acknowledge/transfer-complete indication for the internal BIU interface.
    - biu_err_o: Error termination indication for the internal BIU interface.
Internal reg/wire signals:
    reg [1:0] valid_div: Valid div flag.
    reg [31:0] wb_adr_o: Writeback-stage address output.
    reg wb_cyc_o: Writeback-stage cycle output.
    reg wb_stb_o: Writeback-stage strobe output.
    reg wb_we_o: Writeback-stage write-enable output.
    reg [3:0] wb_sel_o: Writeback-stage select output.
    reg wb_cab_o: Writeback-stage burst cycle output.
    reg [1:0] burst_len: Burst len.
    reg [2:0] wb_cti_o: Writeback-stage cti output.
    reg [31:0] wb_dat_o: Writeback-stage data output.
    reg long_ack_o: Long acknowledge output flag.
    reg long_err_o: Long error output flag.
    reg [31:0] biu_dat_o: Bus interface unit data output.
    wire long_ack_o: Long acknowledge output flag.
    wire long_err_o: Long error output flag.
    wire aborted: Abort flag.
    reg aborted_r: One-cycle registered copy of the abort flag.
    wire retry: Retry flag.
    reg [6:0] retry_cntr: Retry cntr flag.
