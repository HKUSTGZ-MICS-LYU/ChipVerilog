
Module `or1200_except` detects, prioritizes, and encodes OR1200 exceptions and interrupts for precise pipeline redirection.

The file header states: “Handles all OR1K exceptions inside CPU block.”
This module is responsible for:
- recognizing exception conditions
- enforcing exception priority
- generating flush/start signals for exception handling
- saving architectural exception state (EPCR, EEAR, ESR)
- providing PPC/NPC information through SPR-visible outputs
- coordinating exception timing with the pipeline and debug unit

Description:



This module is the centralized exception and interrupt control unit of OR1200. It is responsible for collecting various exception sources in the pipeline, determining priorities, saving EPC/EEAR/ESR, flushing the pipeline and starting exception vector fetching. At the same time, it provides the debugging unit with "exception-stop vector masked by du_dsr". The module uses the rising edge of clk to update the PC/exception flag in the pipeline and the exception state machine, and rst asynchronously resets all exception states. After reset, except_type is set to NONE, extend_flush is set to 0, EPC/EEAR is cleared, and ESR is initialized to the default state specified by the implementation.

The module first sends the IF level instruction fetch address and instruction fetch exception flags (ibuserr, itlbmiss, immufault) to the ID stage on the clock, and then continues to send them to the EX/WB level according to the freeze signal to ensure that the exception is aligned with the corresponding PC. If flushpipe is valid, these pipeline exception information will be cleared. At the same time, the module maintains ex_dslot and its two delayed versions delayed1_ex_dslot and delayed2_ex_dslot, which are used to determine whether the exception occurs in the branch delay slot and which level of PC should be written to the EPC. wb_pc holds the WB level PC for use by delay slot exceptions or debug PPC reads. The module also uses delayed_iee and delayed_tee to delay the revalidation of SR[IEE]/SR[TEE] on the clock to avoid re-accepting interrupts or ticks immediately after l.rfe returns to state.

The exception source is encoded by priority to form except_trig. The order from high to low includes: tick, interrupt, instruction MMU fault, instruction TLB miss, instruction bus error, illegal instruction, address alignment, data TLB miss, data MMU fault, data bus error, range, trap, syscall. Each type of exception is controlled by the corresponding bit of du_dsr at the same time: if the bit is not masked, it will enter except_trig and actually start the exception; if this bit requires debugging to stop, it will enter except_stop without this module directly taking over the control flow. abort_ex is a single combined output that is 1 when dbuserr, dmmufault, dtlbmiss, align or illegal occurs, used to prevent normal writeback of this instruction. int_pending and tick_pending additionally require that the corresponding enable bit in SR is set, the delay enable chain is ready, it is not currently in EX freeze, it is not a branch delay slot, and there is no sr_we in this shot.

There are three sources of flushpipe: except_flushpipe generated by exception detection, external software writing PC request pc_we, and extend_flush initiated by the exception state machine. except_flushpipe is set when except_trig is non-zero and the current exception state machine is idle. except_start is valid when except_type is non-NONE and extend_flush is 1, indicating that the exception vector has been formally submitted to the instruction fetch/PC logic; except_started = extend_flush & except_start. lr_sav outputs ex_pc[31:2], spr_dat_ppc outputs wb_pc, spr_dat_npc takes id_pc when EX is empty, otherwise takes ex_pc.

The exception state machine starts with IDLE. If except_flushpipe is detected, the current sr is immediately latched (if sr_we=1 in this shot, to_sr is saved first) to ESR, and except_type is selected according to the highest priority of except_trig. At the same time, EPC/EEAR is set to the correct PC or access address according to the exception category: for example, ITLB miss/IPF will write the exception-related fetch address into EEAR, and data type exception will write lsu_addr EEAR, many exceptions will write wb_pc to EPC in the delay slot. Then the state machine enters the multi-beat FLU1~FLU5 flushing stage. extend_flush is pulled high in the initial stage and maintained for several beats in subsequent stages to ensure that all old instructions in the pipeline are invalidated and the exception handler starts fetching instructions. Trap exceptions take a shorter path in the current implementation, returning to IDLE earlier. Only after the if_stall is lifted and the ID level is not frozen, the state machine finally returns to IDLE and clears except_type back to NONE.

If there is no new exception but software writes epcr/eear/esr via SPR, these registers can also be updated in the IDLE state; the highest bit of esr is fixed to 1 when written. In summary, this module uniformly defines exception priority, alignment relationship with PC, exception register saving rules and pipeline flushing process, and is the core of OR1200 control flow exception semantics.

module or1200_except(
    // Clock and reset
    input clk,
    input rst,

    // Internal i/f
    input sig_ibuserr,
    input sig_dbuserr,
    input sig_illegal,
    input sig_align,
    input sig_range,
    input sig_dtlbmiss,
    input sig_dmmufault,
    input sig_int,
    input sig_syscall,
    input sig_trap,
    input sig_itlbmiss,
    input sig_immufault,
    input sig_tick,
    input branch_taken,
    input genpc_freeze,
    input id_freeze,
    input ex_freeze,
    input wb_freeze,
    input if_stall,
    input [31:0] if_pc,
    output [31:0] id_pc,
    output [31:2] lr_sav,
    output flushpipe,
    output extend_flush,
    output [3:0] except_type,
    output except_start,
    output except_started,
    output [12:0] except_stop,
    input ex_void,
    output [31:0] spr_dat_ppc,
    output [31:0] spr_dat_npc,
    input [31:0] datain,
    input [13:0] du_dsr,
    input epcr_we,
    input eear_we,
    input esr_we,
    input pc_we,
    output [31:0] epcr,
    output [31:0] eear,
    output [15:0] esr,
    input sr_we,
    input [15:0] to_sr,
    input [15:0] sr,
    input [31:0] lsu_addr,
    output abort_ex,
    input icpu_ack_i,
    input icpu_err_i,
    input dcpu_ack_i,
    input dcpu_err_i
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - sig_ibuserr: Raw instruction-bus-error exception source.
    - sig_dbuserr: Raw data-bus-error exception source.
    - sig_illegal: Raw illegal-instruction exception source.
    - sig_align: Raw alignment exception source.
    - sig_range: Raw range exception source.
    - sig_dtlbmiss: Raw data-TLB-miss exception source.
    - sig_dmmufault: Raw data-MMU-fault exception source.
    - sig_int: Raw interrupt exception source.
    - sig_syscall: Raw system-call exception source.
    - sig_trap: Raw trap exception source.
    - sig_itlbmiss: Raw instruction-TLB-miss exception source.
    - sig_immufault: Raw instruction-MMU-fault exception source.
    - sig_tick: Raw tick-timer exception source.
    - branch_taken: Indicates whether the current branch decision is taken.
    - genpc_freeze: Freeze control for the program-counter generation stage.
    - id_freeze: Freeze control for the decode stage.
    - ex_freeze: Freeze control for the execute stage.
    - wb_freeze: Freeze control for the writeback stage.
    - if_stall: Fetch-stage stall indication.
    - if_pc[31:0]: Program-counter value accompanying the fetched instruction.
    - datain[31:0]: Write data presented to the local storage block.
    - du_dsr[13:0]: Debug-stop register contents forwarded to exception/debug control.
    - epcr_we: Write-enable pulse for the EPCR register.
    - eear_we: Write-enable pulse for the EEAR register.
    - esr_we: Write-enable pulse for the ESR register.
    - pc_we: Program-counter register write-enable pulse.
    - to_sr[15:0]: Composed next value for the system status register.
    - sr_we: Write-enable for the system status register.
    - sr[15:0]: Current system status register value.
    - lsu_addr[31:0]: Effective load/store address forwarded to exception handling.
    - ex_void: Indicates that the execute stage currently holds a void/NOP instruction.
    - icpu_ack_i: Acknowledge/transfer-complete indication for the CPU-to-instruction-memory interface.
    - icpu_err_i: Error termination indication for the CPU-to-instruction-memory interface.
    - dcpu_ack_i: Acknowledge/transfer-complete indication for the CPU-to-data-memory interface.
    - dcpu_err_i: Error termination indication for the CPU-to-data-memory interface.
Output port:
    - id_pc[31:0]: Program-counter value in the decode stage.
    - lr_sav[31:2]: Link-register save value generated for branch/link or exception flow.
    - epcr[31:0]: Exception PC register value.
    - eear[31:0]: Exception effective-address register value.
    - esr[15:0]: Exception status-register value.
    - flushpipe: Pipeline flush request.
    - extend_flush: Extended flush control that keeps the pipeline invalidated for multiple cycles.
    - except_type[3:0]: Encoded exception type driven by the exception controller.
    - except_start: Start pulse for transferring control to an exception vector.
    - except_started: Qualified exception-start indication after flush sequencing.
    - except_stop[12:0]: Encoded exception-stop reason exported to the debug unit.
    - spr_dat_ppc[31:0]: SPR read data for the previous-program-counter register.
    - spr_dat_npc[31:0]: SPR read data for the next-program-counter register.
    - abort_ex: Indicates that the current execute-stage instruction must be aborted.
Internal reg/wire signals:
    reg [3:0] except_type: Exception type.
    reg [31:0] id_pc: Decode-stage program counter.
    reg [31:0] ex_pc: Execute-stage program counter.
    reg [31:0] wb_pc: Writeback-stage program counter.
    reg [31:0] epcr: Exception PC register.
    reg [31:0] eear: Exception address register.
    reg [15:0] esr: Exception status register.
    reg [2:0] id_exceptflags: Decode-stage exceptflags.
    reg [2:0] ex_exceptflags: Execute-stage exceptflags.
    reg [2:0] state: Current exception FSM state register.
    reg extend_flush: Extended pipeline flush request.
    reg extend_flush_last: Registered tail of the extended flush sequence.
    reg ex_dslot: Execute-stage delay slot.
    reg delayed1_ex_dslot: Delayed 1 execute delay slot.
    reg delayed2_ex_dslot: Delayed 2 execute delay slot.
    wire except_started: Registered exception-start state.
    wire [12:0] except_trig: Priority-encoded exception trigger vector; each bit corresponds to one exception class gated by du_dsr.
    wire except_flushpipe: Asserted when except_trig is nonzero and the FSM is idle; initiates exception handler sequencing.
    reg [2:0] delayed_iee: Delayed iee.
    reg [2:0] delayed_tee: Delayed tee.
    wire int_pending: Interrupt pending; gated by SR[IEE], delayed_iee, ex_freeze, branch_taken, ex_dslot, and sr_we.
    wire tick_pending: Tick exception pending; gated by SR[TEE], ex_freeze, branch_taken, ex_dslot, and sr_we.
