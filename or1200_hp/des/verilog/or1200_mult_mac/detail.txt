1. Multiplier behavior
- The module computes a 32x32 product from operands x and y.
- For signed divide operations, operands may be converted to absolute values before the iterative division procedure.
- For multiply instructions, result returns the lower 32 bits of the registered product.
- Multiplier implementation is delegated to either an ASIC-specific or generic 32x32 multiplier submodule.

2. Divider behavior
- Division support is optional under compile-time defines.
- The divider reuses the registered product register as a shift/subtract working register.
- On DIV/DIVU start, the module loads the dividend into the working register and initializes a 32-step counter.
- Each cycle computes `div_tmp = mul_prod_r[63:32] - y` and updates the working register with a shift/subtract step according to the subtraction result.
- For signed divide, the final quotient sign is corrected using operand signs.
- The divider activity (div_cntr != 0) contributes to mac_stall_r to stall the pipeline until the quotient is ready.
3. Result-selection behavior
- For DIV: output quotient, sign-corrected when required.
- For DIVU: output quotient directly.
- For MUL: output lower 32 bits of the registered product.
- Otherwise: output `mac_r[31:0]`, or a shifted window of the MAC accumulator when OR1200_MAC_SHIFTBY is enabled.

4. MAC pipeline behavior
- mac_op is delayed through three sequential registers (mac_op_r1/r2/r3) to align control with the multiplier pipeline latency.
- When delayed mac_op equals MAC, the 64-bit accumulator mac_r is incremented by mul_prod_r.
- When delayed mac_op equals MSB, the accumulator is decremented by mul_prod_r.
- When macrc_op is executed and EX is not frozen, the accumulator is cleared after its value has been consumed.
- SPR write operations (spr_maclo_we / spr_machi_we) have priority over MAC accumulation updates.

5. SPR behavior
- The accumulator is exposed as two 32-bit halves through SPR readback.
- Optional defines allow independent writes to the low and high halves of mac_r through SPR writes.
- spr_addr selects whether the low or high half is accessed.

6. Stall behavior
- mac_stall_r is asserted when MAC operations are still pending in the pipeline and a MAC result read (id_macrc_op) is requested.
- mac_stall_r is also asserted when the divider is active (div_cntr != 0).
- This output is architectural pipeline flow control, not merely a local ready signal.

7. Required functional guarantees
An implementation conforming to this spec shall:
- Implement a 32x32 multiplier whose multiply instruction result is the low 32 bits.
- Maintain a 64-bit MAC accumulator with add and subtract operations.
- Expose accumulator state through SPR readback and optional SPR writes.
- Provide an optional iterative division mode with core stall signaling.
- Align MAC control timing with the multiplier latency so accumulation occurs on the correct product.
