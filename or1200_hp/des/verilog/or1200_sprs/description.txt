
Module `or1200_sprs` decodes and serves OR1200 special-purpose register accesses for system control and status state.

This module is the central decoder and data router for Special Purpose Register (SPR) access. The source comments describe it as “Decoding of SPR addresses and access to SPRs.” It translates l.mfspr/l.mtspr operations and debug-unit accesses into grouped chip-selects, per-register write enables, and a readback data path. It also owns status-register update sequencing for architectural state such as SR, EPCR, EEAR, and ESR.

Description:

The module decodes and serves OR1200 special-purpose register accesses for system control and status state.


This module implements centralized control of SPR (Special Purpose Register) access and system control register updates. It is located between the CPU execution path, the debugging unit and each functional sub-module. It is responsible for converting the `l.mtspr/l.mfspr` instructions or direct access of the debugging unit into a unified SPR address, chip select, write enable and read data return, while maintaining key register control signals such as SR, EPCR, EEAR and ESR in the system group.

First, the module performs unified arbitration on "normal instruction access" and "debug access". `du_access = du_read | du_write`; if debugging access exists, `sprs_op` is forced to `MTSR` or `MFSR`, and `spr_addr` directly takes the debugging address `du_addr`; otherwise, the combination of `alu_op`, `addrbase` and `addrofs` given by the execution unit is used to form the SPR address. Write data `spr_dat_o` takes `du_dat_du` when debugging write, otherwise takes normal data path `dat_i`. `du_dat_cpu` is used for debug unit readback: debug write data is echoed during debug writing, `to_wbmux` is returned during debugging read, and `dat_i` is returned in other cases.

`spr_we` is valid as long as it is a debug write or normal `write_spr`. Chip select `spr_cs` is obtained by ANDing `unqualified_cs` and `{32{read_spr | write_spr}}`, where `unqualified_cs` performs one-hot decoding based on the group number of `spr_addr`, covering 32 possible SPR groups. This way the target group chip select will only be pulled high when an MFSR/MTSR or debug access is actually executed. The module further subdivides the system group internally: `cfgr_sel`, `rf_sel`, `npc_sel`, `ppc_sel`, `sr_sel`, `epcr_sel`, `eear_sel` and `esr_sel` respectively indicate hits to specific system registers.

The update of the system status register SR is the most critical timing behavior of this module. Register `sr` is updated on the rising edge of `clk` with an asynchronous high reset `rst`. After reset the SR is initialized to the architectural initial value with supervisory mode enabled and default exception high bit prefix. Afterwards, if `except_started` is valid, it means that the exception entry has just started. At this time, `SM` is forced to be set to 1 and `TEE/IEE/DME/IME` is cleared, that is, exceptions take precedence over normal writing of SR. If there is no exception and `sr_we` is valid, write the `to_sr` generated by the combination into SR. The enabling conditions of `sr_we` are: normal writing of SR, execution of `RFE`, flag bit update `flag_we` or carry bit update `cy_we`, any of which is true. The generation of `to_sr` also reflects a clear priority: for FO/OV, CY, F, CE:SM and other fields in SR, `RFE` restores the value of `esr` first, followed by separate flag/carry forwarding, then MTSR writing, and finally keeping the original value.

Other register control signals of the system group are exported in combined form: `pc_we` is valid when writing to NPC/PPC, `epcr_we/eear_we/esr_we` is valid when the respective registers are written. Read data `sys_data` OR synthesizes `spr_dat_cfgr`, `spr_dat_rf`, `spr_dat_npc`, `spr_dat_ppc`, `sr`, `epcr`, `eear` and `esr` by address selection through multiple one-hot masking vectors. `flag` and `carry` are respectively exported as aliases of the corresponding bits of SR.

The determination of instruction and debugging access types is completely completed by combinational logic: when `sprs_op` is `MTSR`, `write_spr=1`, `read_spr=0`, `to_wbmux=0`; when it is `MFSR`, `write_spr=0`, `read_spr=1`, and based on the group number of `spr_addr` Select a data source from TT, PIC, PM, DMMU, IMMU, MAC, DU or system group to send to `to_wbmux`; both are 0 under other ALU operations. The entire module is therefore equivalent to the OR1200's SPR crossbar and system control center: exception/RFE updates to the SR take precedence over normal software writes, debug access takes precedence over normal execution access, and read returns are uniquely gated by group number.

module or1200_sprs(
    // Clk & Rst
    input clk,
    input rst,

    // Internal CPU interface
    input flagforw,
    input flag_we,
    output flag,
    input cyforw,
    input cy_we,
    output carry,
    input [31:0] addrbase,
    input [15:0] addrofs,
    input [31:0] dat_i,
    input [3:0] alu_op,
    input [2:0] branch_op,
    input [31:0] epcr,
    input [31:0] eear,
    input [15:0] esr,
    input except_started,
    output [31:0] to_wbmux,
    output epcr_we,
    output eear_we,
    output esr_we,
    output pc_we,
    output sr_we,
    output [15:0] to_sr,
    output [15:0] sr,
    input [31:0] spr_dat_cfgr,
    input [31:0] spr_dat_rf,
    input [31:0] spr_dat_npc,
    input [31:0] spr_dat_ppc,
    input [31:0] spr_dat_mac,

    // From/to other RISC units
    input [31:0] spr_dat_pic,
    input [31:0] spr_dat_tt,
    input [31:0] spr_dat_pm,
    input [31:0] spr_dat_dmmu,
    input [31:0] spr_dat_immu,
    input [31:0] spr_dat_du,
    output [31:0] spr_addr,
    output [31:0] spr_dat_o,
    output [31:0] spr_cs,
    output spr_we,

    input [31:0] du_addr,
    input [31:0] du_dat_du,
    input du_read,
    input du_write,
    output [31:0] du_dat_cpu
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - flagforw: Forwarded next value for the SR flag bit.
    - flag_we: Write-enable for the SR flag bit.
    - cyforw: Forwarded next value for the SR carry bit.
    - cy_we: Write-enable for the SR carry bit.
    - addrbase[31:0]: Base address operand used to form an effective address or SPR address.
    - addrofs[15:0]: Offset operand added to the base address.
    - dat_i[31:0]: Input data word from the upstream datapath.
    - alu_op[3:0]: Major ALU operation selector.
    - branch_op[2:0]: Encoded branch/jump operation selector.
    - epcr[31:0]: Exception PC register value.
    - eear[31:0]: Exception effective-address register value.
    - esr[15:0]: Exception status-register value.
    - except_started: Qualified exception-start indication after flush sequencing.
    - spr_dat_cfgr[31:0]: SPR read data coming from the configuration-register block.
    - spr_dat_rf[31:0]: SPR read data coming from the register-file debug window.
    - spr_dat_npc[31:0]: SPR read data for the next-program-counter register.
    - spr_dat_ppc[31:0]: SPR read data for the previous-program-counter register.
    - spr_dat_mac[31:0]: SPR read data returned by the MAC block.
    - spr_dat_pic[31:0]: SPR read data returned by the PIC block.
    - spr_dat_tt[31:0]: SPR read data returned by the tick-timer block.
    - spr_dat_pm[31:0]: SPR read data returned by the power-management block.
    - spr_dat_dmmu[31:0]: SPR read data returned by the DMMU block.
    - spr_dat_immu[31:0]: SPR read data returned by the IMMU block.
    - spr_dat_du[31:0]: SPR read data returned by the debug-unit block.
    - du_addr[31:0]: Debug-unit internal access address.
    - du_dat_du[31:0]: Write data supplied by the debug unit.
    - du_read: Debug-unit read strobe for CPU-internal accesses.
    - du_write: Debug-unit write strobe for CPU-internal accesses.
Output port:
    - flag: Current flag bit exported from the status-register path.
    - carry: Current carry flag exported from the status-register path.
    - to_wbmux[31:0]: SPR read result forwarded to the writeback multiplexer.
    - epcr_we: Write-enable pulse for the EPCR register.
    - eear_we: Write-enable pulse for the EEAR register.
    - esr_we: Write-enable pulse for the ESR register.
    - pc_we: Program-counter register write-enable pulse.
    - sr_we: Write-enable for the system status register.
    - to_sr[15:0]: Composed next value for the system status register.
    - sr[15:0]: Current system status register value.
    - spr_addr[31:0]: SPR address used for register decode.
    - spr_dat_o[31:0]: Read data returned on the SPR bus.
    - spr_cs[31:0]: SPR chip-select for this module.
    - spr_we: SPR write enable generated by the control path.
    - du_dat_cpu[31:0]: Read data returned from CPU-internal state to the debug unit.
Internal reg/wire signals:
    reg [15:0] sr: Status register.
    reg write_spr: Write SPR.
    reg read_spr: Read SPR.
    reg [31:0] to_wbmux: To writeback mux.
    wire cfgr_sel: Configuration register select.
    wire rf_sel: Register file select.
    wire npc_sel: Next PC select.
    wire ppc_sel: Previous PC select.
    wire sr_sel: Status register select.
    wire epcr_sel: Exception PC register select.
    wire eear_sel: Exception address register select.
    wire esr_sel: Exception status register select.
    wire [31:0] sys_data: Sys data.
    wire du_access: Debug unit access.
    wire [3:0] sprs_op: SPR subsystem operation.
    reg [31:0] unqualified_cs: Unqualified chip-select.
    wire [31:0] read_spr_cfgr_sel_32: Stage-32 pipeline copy of the read SPR configuration register select.
    wire [31:0] read_spr_rf_sel_32: Stage-32 pipeline copy of the read SPR register file select.
    wire [31:0] read_spr_npc_sel_32: Stage-32 pipeline copy of the read SPR next PC select.
    wire [31:0] read_spr_ppc_sel_32: Stage-32 pipeline copy of the read SPR previous PC select.
    wire [31:0] read_spr_sr_sel_32: Stage-32 pipeline copy of the read SPR status register select.
    wire [31:0] read_spr_epcr_sel_32: Stage-32 pipeline copy of the read SPR exception PC register select.
    wire [31:0] read_spr_eear_sel_32: Stage-32 pipeline copy of the read SPR exception address register select.
    wire [31:0] read_spr_esr_sel_32: Stage-32 pipeline copy of the read SPR exception status register select.
    wire [31:0] sr_32: Stage-32 pipeline copy of the status register.
    wire [31:0] esr_32: Stage-32 pipeline copy of the exception status register.
