1. Address formation and access-source selection
- A normal CPU SPR access uses spr_addr = du_access ? du_addr : (addrbase | {16'h0, addrofs}).
- A debug-unit SPR access overrides the normal address and uses du_addr.
- A debug-unit write overrides normal write data and uses du_dat_du.
- du_read or du_write marks a debug-unit transaction.

2. Operation decoding
- If the active operation is l.mtspr, the block asserts write_spr and deasserts read_spr.
- If the active operation is l.mfspr, the block asserts read_spr and deasserts write_spr.
- For debug access, du_write behaves like l.mtspr and du_read behaves like l.mfspr.
- spr_we = du_write | write_spr.

3. Group decoding
- The SPR address group field is decoded into a 32-bit one-hot unqualified chip-select vector.
- spr_cs is the qualified version of that vector and is only asserted during an active read_spr or write_spr access.
- This design allows each architectural block to receive a group-specific select bit rather than re-decoding the full address globally.

4. System SPR behavior
The module directly handles system-group registers including:
- CFGR read access.
- RF read/write access redirection.
- NPC and PPC selection.
- SR read/write/update.
- EPCR, EEAR, ESR read/write.

5. Status register semantics
- SR update follows strict priority: if (rst), SR is initialized to the architectural reset value; else if (except_started), SR forces supervisor mode and clears TEE/IEE/DME/IME; else if (sr_we), SR is updated with to_sr. sr_we itself is asserted by any of: direct SPR write to SR, RFE branch, flag_we, or cy_we.
- On reset, SR is initialized with supervision enabled and the default exception-prefix bit value.
- On exception start, SR forces supervisor mode and disables TEE, IEE, DME, and IME.
- On RFE, selected fields are restored from ESR.
- flag_we and cy_we can update SR[F] and SR[CY] independently of a general SPR write.

6. Readback mux behavior
When reading an SPR:
- TT group returns spr_dat_tt.
- PIC group returns spr_dat_pic.
- PM group returns spr_dat_pm.
- DMMU group returns spr_dat_dmmu.
- IMMU group returns spr_dat_immu.
- MAC group returns spr_dat_mac.
- DU group returns spr_dat_du.
- SYS group returns locally assembled sys_data.
- Unimplemented or unmatched groups return zero.

7. sys_data composition
sys_data is the bitwise OR of all system-group readback sources, where each source is individually gated as (source_data & {32{read_spr & sel}}). Only the selected source produces nonzero bits; all others are masked to zero. This means the implementation uses OR-reduction across all masked sources rather than a case/mux structure.

8. Required functional guarantees
An implementation conforming to this spec shall:
- Support both instruction-driven and debug-unit-driven SPR accesses.
- Decode the SPR group field into one-hot chip-selects.
- Generate readback data for all system-group architectural registers.
- Correctly update SR on reset, exception entry, RFE, direct SPR writes, and flag/carry forwarding.
- Generate epcr_we, eear_we, esr_we, pc_we, and sr_we exactly when their target registers must update.
- Route debug-unit write/read data consistently so the debug unit can observe the same architectural view as the CPU.
