
Module `or1200_pic` implements programmable interrupt masking, latching, and interrupt-request signaling to core control logic.

This module implements the Programmable Interrupt Controller according to the OR1K architectural specification. It receives external interrupt lines, masks them, records pending status, and generates the consolidated processor interrupt request and a wakeup request for power management.

Description:


This module implements the programmable interrupt controller (PIC) and is responsible for masking external interrupt inputs, maintaining status, SPR read and write access, and outputting the final interrupt request to the CPU. The module also synchronously outputs whether there is an unmasked interrupt as `pic_wakeup` for the power management unit to use as a wake-up condition.

When `OR1200_PIC_IMPLEMENTED` is enabled, the module contains optional interrupt mask register `picmr` and interrupt status register `picsr`, both updated on the rising edge of `clk` with an asynchronous high reset `rst`. After reset, `picmr` is initialized to {1'b1, {OR1200_PIC_INTS-3{1'b0}}}, while the lowest two bits are implicitly unmasked through {picmr, 2'b11}, that is, the high bit is cleared and the lowest two bits are implicitly 1; `picsr` is cleared. `picmr` is only overwritten by the CPU when the address selection hits PICMR and `spr_write` is valid. `picsr` is then both writable by the CPU via SPR and will automatically OR on every beat the current unmasked interrupt `um_ints`, accumulated as picsr <= picsr | um_ints, and may be modified by software writes.

In combinational logic, `picmr_sel` and `picsr_sel` are decoded according to `spr_cs` and `spr_addr`; `um_ints = pic_int & {picmr, 2'b11}` represents the effective interrupt set obtained after external interrupts are first masked, of which the lowest two bits are always unmaskable. `intr` is pulled high as long as any bit of `um_ints` is 1, so the output to the CPU is a merge request of "there is currently at least one unmasked interrupt" instead of the encoded interrupt number. `pic_wakeup` is directly equal to `intr`, which means that whenever an unmasked interrupt arrives, a request is made to exit the low-power state.

The SPR read interface is implemented by combinational logic: if the PICMR address is accessed, `{picmr,2'b0}` is returned; otherwise, `picsr` is returned by default. If the unused bit clear option is defined, the remaining bits above the actual number of interrupts return 0. There is no dedicated priority encoder inside the module, so the interrupt priority is not determined here, but is handled by the CPU exception entry or external software convention.

If the PIC implementation is not enabled, the module degenerates into the simplest mode: `intr` is directly equal to the OR of the lowest two external interrupt inputs, `pic_wakeup` follows `intr`, and the SPR read port returns 0. That is, there are no programmable masks and state retention in this configuration.

module or1200_pic(
    // RISC Internal Interface
    input clk,
    input rst,
    input spr_cs,
    input spr_write,
    input [31:0] spr_addr,
    input [31:0] spr_dat_i,
    output [31:0] spr_dat_o,
    output pic_wakeup,
    output intr,

    // PIC Interface
    input [19:0] pic_int
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - spr_cs: SPR chip-select for this module.
    - spr_write: SPR write strobe for this module.
    - spr_addr[31:0]: SPR address used for register decode.
    - spr_dat_i[31:0]: Write data from the SPR/control path.
    - pic_int[19:0]: Interrupt request vector entering the PIC block.
Output port:
    - spr_dat_o[31:0]: Read data returned on the SPR bus.
    - pic_wakeup: Programmable interrupt controller wakeup.
    - intr: Combined interrupt request output.
Internal reg/wire signals:
    reg [19:2] picmr: PIC mask register.
    wire [19:2] picmr: PIC mask register.
    reg [19:0] picsr: PIC status register.
    wire [19:0] picsr: PIC status register.
    wire picmr_sel: PIC mask register select.
    wire picsr_sel: PIC status register select.
    wire [19:0] um_ints: Unmasked interrupt vector; computed as pic_int & {picmr, 2'b11}
    reg [31:0] spr_dat_o: SPR data output.
