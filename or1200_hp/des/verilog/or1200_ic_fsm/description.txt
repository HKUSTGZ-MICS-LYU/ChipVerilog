
Module `or1200_ic_fsm` controls instruction-cache refill and miss-handling state transitions for fetch-side memory requests.

This module is the instruction-cache finite-state machine. It controls cache-hit evaluation, cache-line refill, first-word acknowledgment, refill burst generation, and write enables for the data RAM and tag RAM.

Description:

The module controls instruction-cache refill and miss-handling state transitions for fetch-side memory requests.


This module implements the instruction cache control state machine and is responsible for handling fetch hits, first word returns after misses, full line backfilling, and cache-inhibit accesses when the instruction cache is enabled. The core goal of the module is to generate control signals for the data RAM, Tag RAM and external bus based on the tag comparison results and the response/error returned by the external BIU after the CPU initiates an instruction fetch request, and return the first word response to the upper layer at the appropriate time.

The module updates status on the rising edge of `clk` with an asynchronous high reset `rst`. After reset, the status enters `IDLE` and `saved_addr_r`, `cnt`, `hitmiss_eval`, `load` and `cache_inhibit` are all cleared. After entering the idle state, new instruction fetches will be accepted only when `ic_en` and `icqmem_cycstb_i` are valid at the same time, and `start_addr` will be latched to `saved_addr_r`, and `hitmiss_eval` and `load` will be set at the same time, and the instruction fetch state `CFETCH` will be entered. `saved_addr` always outputs the registered `saved_addr_r` to the outside world, so the backfill address and hit comparison are based on the registered value instead of directly using the instantaneous `start_addr`.

In the `CFETCH` state, if the current access is marked as cache-inhibit, `cache_inhibit` is set, indicating that the access should not be written to the Cache. This state first uses `hitmiss_eval` and `tagcomp_miss` to decide whether a BIU read needs to be actually initiated: `biu_read` is valid when "first evaluation and miss" or "subsequent backfill still needs to be loaded". If any of the following conditions occurs, the state machine returns to `IDLE` immediately: Cache is closed, the request is revoked during first evaluation, BIU returns an error, or cache-inhibit access has obtained external return data. If there is a miss and the first `biudata_valid` is received, the state machine considers that the first word has arrived, first increments the low bit of the current address, loads the backfill count `cnt = ICLS-2`, clears `hitmiss_eval`, and then transfers to `LREFILL3` to continue backfilling the entire line of the remaining words. If there is a hit and the page is not cache-inhibited, the access will be completed immediately without leaving the address context saved by `CFETCH` and preparing to return to idle. If the request is canceled before completion, it will also be returned directly to `IDLE`.

The `LREFILL3` state is used to handle subsequent backfilling of the entire cache line. Each time `biudata_valid` is received, if `cnt` is non-zero, continue to count down and increment the low bit of the address; when the last word returns, the state machine returns to `IDLE`, clears `hitmiss_eval/load`, and restores `saved_addr_r` to the new `start_addr`. `burst` is high when "CFETCH and miss occurs and is not cache-inhibited" or "in LREFILL3" to indicate to the upper layer that the current bus access belongs to a full row backfill burst.

In terms of output semantics, `icram_we` and `tag_we` are only valid when the BIU is reading, receiving a valid return, and this access is not cache-inhibited, so only truly cacheable data will be written to the data RAM and tag RAM. `first_hit_ack` is only raised high when the first hit occurs in the `CFETCH` state; `first_miss_ack` and `first_miss_err` are raised respectively when the first word is missed or the first word returns an error. There is no additional complex priority chain in the entire module. The priority of state transfer is clearly reflected as follows: shutdown/undo/error/cache-inhibit completion takes precedence over miss backfill, miss backfill takes precedence over hit completion, and hit completion takes precedence over continued waiting.

module or1200_ic_fsm(
    // Clock and reset
    input clk,
    input rst,

    // Internal i/f to top level IC
    input ic_en,
    input icqmem_cycstb_i,
    input icqmem_ci_i,
    input tagcomp_miss,
    input biudata_valid,
    input biudata_error,
    input [31:0] start_addr,
    output [31:0] saved_addr,
    output [3:0] icram_we,
    output biu_read,
    output first_hit_ack,
    output first_miss_ack,
    output first_miss_err,
    output burst,
    output tag_we
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - ic_en: Instruction-cache enable control.
    - icqmem_cycstb_i: Combined cycle-and-strobe request for the instruction-cache/QMEM interface.
    - icqmem_ci_i: Cache-inhibit attribute for the instruction-cache/QMEM interface.
    - tagcomp_miss: Combinational tag-compare miss indication.
    - biudata_valid: Indicates that returned BIU read data is valid.
    - biudata_error: Indicates that the current BIU access terminated with an error.
    - start_addr[31:0]: Starting address captured for the current cache transaction.
Output port:
    - saved_addr[31:0]: Saved request address held by the FSM during refill or replay.
    - icram_we[3:0]: Byte-write enable for the instruction-cache RAM.
    - biu_read: Read request issued by the cache/controller FSM to the external BIU.
    - first_hit_ack: One-cycle acknowledge for a cache hit or immediately satisfied access.
    - first_miss_ack: One-cycle acknowledge for the first returned word of a miss/refill access.
    - first_miss_err: One-cycle error indication for the first word of a miss/refill access.
    - burst: Indicates that the current external transfer belongs to a burst/refill sequence.
    - tag_we: Write enable for the tag RAM.
Internal reg/wire signals:
    reg [31:0] saved_addr_r: One-cycle registered copy of the saved address.
    reg [1:0] state: State.
    reg [2:0] cnt: Count counter.
    reg hitmiss_eval: Hit/miss evaluation flag.
    reg load: Load flag.
    reg cache_inhibit: Cache inhibit.
