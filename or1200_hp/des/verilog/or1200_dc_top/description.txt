
Module `or1200_dc_top` integrates OR1200 data-cache datapath/control with CPU-side requests and external memory bus signaling.

The file header states simply “Data cache.” This module is the complete data-cache subsystem wrapper. It connects:
- the LSU-side internal request interface
- the external system/bus interface
- the data RAM
- the tag RAM
- the data-cache FSM
- optional cache invalidation via SPR writes

Description:



This module is the top layer of the OR1200 data cache, located between the LSU/data side internal interface and the external data bus. It is responsible for combining address, write data, tag RAM, data RAM and data cache state machine to implement hit return, miss first word pass-through, full row backfill, software failure and bypass access when the cache is closed. The module uses clk/rst to drive the internal state machine and memory bank. The external interface includes dcsb_* bus signals. The internal interface includes dcqmem_* request and return signals from LSU/MMU, and a set of control ports used to perform cache line invalidation through SPR.

When dc_en is 0, this module basically bypasses the cache: dcsb_cyc_o and dcsb_stb_o directly follow dcqmem_cycstb_i, dcsb_we_o follows dcqmem_we_i, dcsb_sel_o follows dcqmem_sel_i, and returns data dcqmem_dat_o Take the external bus dcsb_dat_i directly, ack/error also comes directly from the external bus, dcqmem_tag_o is only rewritten to the bus error tag when there is an error. In this way, hit, backfill, or tag comparison semantics will not be preserved when the data cache is closed. dcqmem_rty_o is obtained by combining ~dcqmem_ack_o, which means it remains in the "waiting" state until it is confirmed.

When dc_en is 1, the module enables tag RAM, data RAM, and dcfsm. dcfsm controls external reading and writing and local RAM updates based on the request type, tag comparison result and bus return; dc_addr comes from the current LSU address at the beginning of a normal request and comes from the state machine save address saved_addr during miss backfill. External write data dcsb_dat_o always takes the dcqmem_dat_i provided by the LSU; when writing a hit, dcfsm generates dcram_we selected by byte, performs a write update on the hit word of the data RAM, and the external bus also performs write-through. When reading a miss, the first external return data is returned directly to LSU through dcqmem_dat_o on the one hand, and written into data RAM through to_dcram on the other hand; subsequent backfill words continue to be written into data RAM until the entire row is completed. When reading hit, dcqmem_dat_o is taken directly from the data RAM output from_dcram.

The tag comparison logic is purely combinational: if the tag read from the tag RAM is inconsistent with the high bits of saved_addr, or tag_v is 0, then tagcomp_miss=1; otherwise, it is considered a hit. The tag RAM write enable dctag_we comes from two sources: one is the write tag request issued by dcfsm during the read miss backfill process; the other is the invalidation command dc_inv initiated by the software through SPR. The priority of the failed command is reflected in dctag_we=dctag_fsm_we|dc_inv, and when it fails, dctag_addr is forced to take the index given in spr_dat_i, and dctag_v is set to 0, so the software will clear the valid bit of the corresponding tag line when writing SPR. Under normal circumstances, dctag_addr takes the index corresponding to the current dc_addr, and dctag_v is 1. data RAM is only enabled when dc_en is valid, tag RAM is enabled when dc_en or dc_inv.

The completion signal for the upstream LSU is divided into hit completion and miss first word completion: dcqmem_ack_o is generated by dcfsm_first_hit_ack or dcfsm_first_miss_ack when dc_en=1, and dcqmem_err_o is generated by dcfsm_first_miss_err. From this, LSU only cares about the first visible completion moment, while backfilling of the entire row can continue in the background. On the whole, this module unifies cache hit path, miss pass-through return, write-through, whole-row backfill and software failure into one top layer.

module or1200_dc_top(
    // Rst, clk and clock control
    input clk,
    input rst,

    // External i/f
    output [31:0] dcsb_dat_o,
    output [31:0] dcsb_adr_o,
    output dcsb_cyc_o,
    output dcsb_stb_o,
    output dcsb_we_o,
    output [3:0] dcsb_sel_o,
    output dcsb_cab_o,
    input [31:0] dcsb_dat_i,
    input dcsb_ack_i,
    input dcsb_err_i,

    // Internal i/f
    input dc_en,
    input [31:0] dcqmem_adr_i,
    input dcqmem_cycstb_i,
    input dcqmem_ci_i,
    input dcqmem_we_i,
    input [3:0] dcqmem_sel_i,
    input [3:0] dcqmem_tag_i,
    input [31:0] dcqmem_dat_i,
    output [31:0] dcqmem_dat_o,
    output dcqmem_ack_o,
    output dcqmem_rty_o,
    output dcqmem_err_o,
    output [3:0] dcqmem_tag_o,

`ifdef OR1200_BIST
    // RAM BIST
    input mbist_si_i,
    output mbist_so_o,
    input [`OR1200_MBIST_CTRL_WIDTH - 1:0] mbist_ctrl_i,
`endif

    // SPRs
    input spr_cs,
    input spr_write,
    input [31:0] spr_dat_i
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - dcsb_dat_i[31:0]: Data bus for the data-cache to store-buffer interface.
    - dcsb_ack_i: Acknowledge/transfer-complete indication for the data-cache to store-buffer interface.
    - dcsb_err_i: Error termination indication for the data-cache to store-buffer interface.
    - dc_en: Data-cache enable control.
    - dcqmem_adr_i[31:0]: Address bus for the data-cache/QMEM interface.
    - dcqmem_cycstb_i: Combined cycle-and-strobe request for the data-cache/QMEM interface.
    - dcqmem_ci_i: Cache-inhibit attribute for the data-cache/QMEM interface.
    - dcqmem_we_i: Write-enable / write-versus-read qualifier for the data-cache/QMEM interface.
    - dcqmem_sel_i[3:0]: Byte-lane select for the data-cache/QMEM interface.
    - dcqmem_tag_i[3:0]: Tag field carried on the data-cache/QMEM interface.
    - dcqmem_dat_i[31:0]: Data bus for the data-cache/QMEM interface.
    - mbist_si_i: MBIST serial scan input. Present only when `OR1200_BIST` is enabled.
    - mbist_ctrl_i[`OR1200_MBIST_CTRL_WIDTH - 1:0]: MBIST control bus. Present only when `OR1200_BIST` is enabled.
    - spr_cs: SPR chip-select for this module.
    - spr_write: SPR write strobe for this module.
    - spr_dat_i[31:0]: Write data from the SPR/control path.
Output port:
    - dcsb_dat_o[31:0]: Data bus for the data-cache to store-buffer interface.
    - dcsb_adr_o[31:0]: Address bus for the data-cache to store-buffer interface.
    - dcsb_cyc_o: Cycle-valid request for the data-cache to store-buffer interface.
    - dcsb_stb_o: Strobe/request-valid qualifier for the data-cache to store-buffer interface.
    - dcsb_we_o: Write-enable / write-versus-read qualifier for the data-cache to store-buffer interface.
    - dcsb_sel_o[3:0]: Byte-lane select for the data-cache to store-buffer interface.
    - dcsb_cab_o: Consecutive-address burst indication for the data-cache to store-buffer interface.
    - dcqmem_dat_o[31:0]: Data bus for the data-cache/QMEM interface.
    - dcqmem_ack_o: Acknowledge/transfer-complete indication for the data-cache/QMEM interface.
    - dcqmem_rty_o: Retry/wait indication for the data-cache/QMEM interface.
    - dcqmem_err_o: Error termination indication for the data-cache/QMEM interface.
    - dcqmem_tag_o[3:0]: Tag field carried on the data-cache/QMEM interface.
    - mbist_so_o: MBIST serial scan output. Present only when `OR1200_BIST` is enabled.
Internal reg/wire signals:
    wire tag_v: Cache-tag valid bit.
    wire [18:0] tag: Cache-tag value read from the data-cache tag RAM.
    wire [31:0] to_dcram: Write data selected between BIU refill data and LSU store data.
    wire [31:0] from_dcram: Read data returned from the data cache RAM.
    wire [31:0] saved_addr: Saved address.
    wire [3:0] dcram_we: Dcram write-enable.
    wire dctag_we: Data-cache tag RAM write-enable.
    wire [31:0] dc_addr: Data cache address.
    wire dcfsm_biu_read: Data-cache FSM bus interface unit read.
    wire dcfsm_biu_write: Data-cache FSM bus interface unit write.
    reg tagcomp_miss: Tag-compare miss flag.
    wire [12:4] dctag_addr: Data-cache tag RAM address.
    wire dctag_en: Data-cache tag RAM enable flag.
    wire dctag_v: Data-cache tag RAM valid.
    wire dc_inv: Data-cache invalidate request.
    wire dcfsm_first_hit_ack: Data-cache FSM first hit acknowledge.
    wire dcfsm_first_miss_ack: Data-cache FSM first miss acknowledge.
    wire dcfsm_first_miss_err: Data-cache FSM first miss error flag.
    wire dcfsm_burst: Data-cache FSM burst.
    wire dcfsm_tag_we: Data-cache FSM tag write-enable.
    wire mbist_ram_so: MBIST RAM serial output.
    wire mbist_tag_so: MBIST tag serial output.
    wire mbist_ram_si = mbist_si_i: MBIST RAM serial input flag.
    wire mbist_tag_si = mbist_ram_so: MBIST tag serial input.
    wire [31:12] dc_tag_datain: Data cache tag datain.
