1. Structural Composition
The RTL instantiates:
- or1200_dc_fsm
- or1200_dc_ram
- or1200_dc_tag

2. Functional Specification
2.1 Address and control routing
The module shall drive dcsb_adr_o from the effective cache/BIU address dc_addr generated by the FSM/top logic.

2.2 Cache invalidation path
The RTL defines:
- dc_inv = spr_cs & spr_write
- dctag_we = dcfsm_tag_we | dc_inv
- dctag_addr = invalidation-selected index or current cache index
- dctag_v = ~dc_inv
Therefore:
- an SPR write into this block invalidates a selected cache line by writing a tag entry with valid=0
- normal refill writes use dcfsm_tag_we and valid=1

3. Data-path selection
3.1 Write data to the external bus
dcsb_dat_o shall be driven directly from dcqmem_dat_i, i.e. the LSU write data path.

3.2 Cache-enabled versus bypass control
The block shall bypass the cache when dc_en is false:
- dcsb_cyc_o/stb_o follow dcqmem_cycstb_i
- dcsb_we_o follows dcqmem_we_i
- dcsb_sel_o follows the LSU select
- dcqmem_ack_o follows dcsb_ack_i
- dcqmem_err_o follows dcsb_err_i

When dc_en is true, the block shall instead use the dc_fsm-generated bus controls.

3.3 Select lines for cached reads
For BIU read refills, dcsb_sel_o is forced to 4'b1111 so the whole 32-bit word is fetched.
Otherwise it follows the request byte select.

3.4 Data into DCRAM
to_dcram shall be:
- BIU data during refill reads
- LSU write data during stores

3.5 Data returned to LSU
dcqmem_dat_o shall be:
- BIU data when a first miss acknowledge occurs or when cache is disabled
- cache RAM data on cache hits

4. Tag Compare
The block performs hit/miss determination by comparing:
- stored tag from dc_tag
- saved_addr upper tag bits
and checking tag_v.
If tag mismatch or invalid bit clear, tagcomp_miss is asserted.

5. Handshake / response rules
- dcqmem_ack_o indicates successful completion to the LSU side
- dcqmem_err_o indicates fault
- dcqmem_rty_o is driven as the inverse of ack in this design
- dcqmem_tag_o passes the incoming tag unless an error occurs, in which case the bus-error tag OR1200_DTAG_BE is returned

6. Implementation Constraints
A compatible implementation shall preserve:
- the cache-enabled/bypass split
- hit/miss data return behavior
- refill and invalidation semantics
- external bus handshake behavior
- the interaction contract with dc_fsm, dc_ram, and dc_tag
