Functional Overview:
Module `or1200_immu_top` integrates instruction-side MMU translation, TLB access, and fault signaling for fetch requests.

This module is the instruction-side MMU top-level wrapper. It combines the ITLB with fetch-side control logic so the processor can present virtual instruction addresses while the downstream memory/cache subsystem sees translated physical addresses; in this implementation the cache-inhibit output is forced to the architectural constant rather than taken from the ITLB entry.

Description:
This module implements the top level of the instruction MMU and is responsible for completing ITLB query, physical address formation, TLB miss/page protection exception detection, and SPR access arbitration of ITLB on the instruction access path. The module is located between the CPU and the downstream instruction fetch storage system: the CPU provides virtual addresses and instruction fetch requests, and the module outputs physical addresses to the downstream stage or blocks access when exceptions occur, and reports miss/fault through `icpu_err_o` and `icpu_tag_o`.

In terms of timing behavior, the module updates multiple registers on the rising edge of `clk` and has an asynchronous high level reset `rst`. `icpu_adr_o` is a sequential output in implementations with `OR1200_REGISTERED_OUTPUTS` enabled, is set to `0x00000100` after reset, and `icpu_adr_i` is latched on every beat thereafter. `icpu_vpn_r` always latches the current virtual page number every beat, which is used to maintain the previous VPN in scenarios where the page spans or the PPN is obtained with a delay of one beat. The VPN register is cleared after reset. If IMMU is enabled, `dis_spr_access` is used to mask normal ITLB exception detection on the first cycle of accessing the ITLB SPR: set when `spr_cs` is asserted and cleared when `icpu_rty_o` deasserts. `itlb_en_r` delays `itlb_en` by one beat and suppresses it during ITLB SPR access, so that `itlb_done` is only true if "an ITLB query was actually issued in the last beat and there is no current page span".

In combination logic, `page_cross` detects whether the page number of the current fetch address is different from `icpu_vpn_r`; once it crosses the page, the current access will not be sent directly to the lower level. If `OR1200_NO_IMMU` is not defined, the module will determine whether it has obtained a stable ITLB table lookup result based on `itlb_done` when IMMU is enabled. `miss` is established when `itlb_done` and `itlb_hit` is 0; `fault` is established when `itlb_done` and the current execution permission is not satisfied: `itlb_uxe` is required in user mode and `itlb_sxe` is required in privileged mode. The priority of the output tag `icpu_tag_o` is miss higher than fault, and higher than the lower-level return tag, that is, miss outputs the TLB miss tag, fault outputs the page exception tag, and in other cases, the lower-level tag is transparently transmitted. The error output `icpu_err_o` is valid as long as any condition of miss, fault or subsequent error occurs.

Requests to the back-end storage system are made only when allowed. `qmemimmu_cycstb_o` requires that when IMMU is enabled: the current CPU has an instruction fetch request, no miss, no fault, no page crossing, and `itlb_done` is already valid; if IMMU is turned off, directly press `icpu_cycstb_i & ~page_cross` for transparent transmission. The physical address `qmemimmu_adr_o` is concatenated with the PPN returned by ITLB and the current page offset when `itlb_done` is used, otherwise the previously registered virtual page number icpu_vpn_r is concatenated with the current page offset. This implementation ensures that when the table lookup result lags behind by one beat, the high bits of the address still use the page number that matches the request. `qmemimmu_ci_o` is fixed to the architectural constant `OR1200_IMMU_CI` in this implementation, and the cache-inhibit bit returned by ITLB is not actually taken; a comment is explicitly left in the code stating that this is to avoid asynchronous composition loops.

In terms of SPR interface, `spr_dat_o` returns ITLB's SPR read data when `spr_cs` is valid, otherwise it outputs 0; `itlb_spr_access` is `spr_cs & ~dis_spr_access`, and the access will pass `icpu_rty_o = qmemimmu_rty_i | (itlb_spr_access & immu_en)` Create a wait for the predecessor to ensure that SPR accesses are mutually exclusive with normal instruction fetches. If the IMMU is completely turned off, this module degenerates into a simple path: the address is transparently transmitted as it is, the error/retry tags come from the downstream stage, the SPR read data is 0, and the BIST link is directly bypassed.

Module name:
module or1200_immu_top(
    // Rst and clk
    input clk,
    input rst,

    // CPU i/f
    input ic_en,
    input immu_en,
    input supv,
    input [31:0] icpu_adr_i,
    input icpu_cycstb_i,
    output [31:0] icpu_adr_o,
    output [3:0] icpu_tag_o,
    output icpu_rty_o,
    output icpu_err_o,

    // SPR access
    input spr_cs,
    input spr_write,
    input [31:0] spr_addr,
    input [31:0] spr_dat_i,
    output [31:0] spr_dat_o,

`ifdef OR1200_BIST
    // RAM BIST
    input mbist_si_i,
    output mbist_so_o,
    input [`OR1200_MBIST_CTRL_WIDTH - 1:0] mbist_ctrl_i,
`endif

    // QMEM i/f
    input qmemimmu_rty_i,
    input qmemimmu_err_i,
    input [3:0] qmemimmu_tag_i,
    output [31:0] qmemimmu_adr_o,
    output qmemimmu_cycstb_o,
    output qmemimmu_ci_o
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - ic_en: Instruction-cache enable control.
    - immu_en: Instruction-MMU enable control.
    - supv: Current supervisor-mode status used for privileged behavior and permission checks.
    - icpu_adr_i[31:0]: Address bus for the CPU-to-instruction-memory interface.
    - icpu_cycstb_i: Combined cycle-and-strobe request for the CPU-to-instruction-memory interface.
    - spr_cs: SPR chip-select for this module.
    - spr_write: SPR write strobe for this module.
    - spr_addr[31:0]: SPR address used for register decode.
    - spr_dat_i[31:0]: Write data from the SPR/control path.
    - mbist_si_i: MBIST serial scan input. Present only when `OR1200_BIST` is enabled.
    - mbist_ctrl_i[`OR1200_MBIST_CTRL_WIDTH - 1:0]: MBIST control bus. Present only when `OR1200_BIST` is enabled.
    - qmemimmu_rty_i: Retry/wait indication for the downstream instruction-memory path after IMMU/QMEM arbitration.
    - qmemimmu_err_i: Error termination indication for the downstream instruction-memory path after IMMU/QMEM arbitration.
    - qmemimmu_tag_i[3:0]: Tag field carried on the downstream instruction-memory path after IMMU/QMEM arbitration.
Output port:
    - icpu_adr_o[31:0]: Address bus for the CPU-to-instruction-memory interface.
    - icpu_tag_o[3:0]: Tag field carried on the CPU-to-instruction-memory interface.
    - icpu_rty_o: Retry/wait indication for the CPU-to-instruction-memory interface.
    - icpu_err_o: Error termination indication for the CPU-to-instruction-memory interface.
    - spr_dat_o[31:0]: Read data returned on the SPR bus.
    - mbist_so_o: MBIST serial scan output. Present only when `OR1200_BIST` is enabled.
    - qmemimmu_adr_o[31:0]: Address bus for the downstream instruction-memory path after IMMU/QMEM arbitration.
    - qmemimmu_cycstb_o: Combined cycle-and-strobe request for the downstream instruction-memory path after IMMU/QMEM arbitration.
    - qmemimmu_ci_o: Cache-inhibit attribute for the downstream instruction-memory path after IMMU/QMEM arbitration.
Internal reg/wire signals:
    wire itlb_spr_access: SPR-access request targeting the instruction TLB.
    wire [31:13] itlb_ppn: Physical page number returned by the instruction TLB.
    wire itlb_hit: Instruction-TLB hit flag.
    wire itlb_uxe: Instruction-TLB user-execute permission bit.
    wire itlb_sxe: Instruction-TLB supervisor-execute permission bit.
    wire [31:0] itlb_dat_o: Raw data word read from the instruction TLB.
    wire itlb_en: Instruction-TLB enable flag.
    wire itlb_ci: Instruction-TLB cache-inhibit attribute.
    wire itlb_done: Instruction-TLB lookup-complete flag.
    wire fault: Instruction address translation-fault flag.
    wire miss: Instruction-TLB miss flag.
    wire page_cross: Flag that the fetch crosses a page boundary.
    reg [31:0] icpu_adr_o: Registered copy of `icpu_adr_i` when `OR1200_REGISTERED_OUTPUTS` is enabled.
    reg [31:13] icpu_vpn_r: Registered virtual page number of the fetch address.
    reg itlb_en_r: Registered copy of the instruction-TLB enable flag.
    reg dis_spr_access: Flag that disables SPR access for this request.
