Functional Overview:
Module `or1200_iwb_biu` adapts OR1200 instruction-side bus requests to Wishbone transactions and returns fetched instruction data.

This module is the instruction/data-side Wishbone bus interface unit for OR1200 internal BIU-style requests. It converts a simple internal RISC bus transaction interface into Wishbone bus cycles and returns acknowledgments, errors, and read data back to the core.

Description:
This module is the OR1200 command side WISHBONE bus interface unit (BIU). It is responsible for converting the internal BIU request signal biu_* to the external WISHBONE master device signal wb_*, and synchronizing the ack/err/rty/data of the external bus back to the internal interface. The module also supports the cooperation of the internal RISC clock clk/rst and the external WISHBONE clock wb_clk_i/wb_rst_i, and supports WISHBONE running in the same frequency, 1/2 frequency or 1/4 frequency mode as RISC through clmode. The status of the module is updated in the RISC clock domain and WISHBONE clock domain respectively, and the reset signal has the highest priority for the registers in the respective clock domains.

On the basic data path, wb_adr_o, wb_dat_o, wb_cyc_o, wb_stb_o, wb_we_o, wb_sel_o and optional wb_cab_o, wb_cti_o, wb_bte_o are driven by internal requests; if registered output is enabled, these signals are registered on wb_clk_i, otherwise they are directly combined and transparently transmitted. On the read return path, if registered input is enabled, wb_dat_i, wb_ack_i, and wb_err_i will first be registered on wb_clk_i as biu_dat_o, long_ack_o, and long_err_o; otherwise, they will be used in combination directly. biu_ack_o and biu_err_o further turn into a RISC cycle-wide confirmation/error pulse in the RISC clock domain according to the beat window of clmode. Therefore, when the external WISHBONE is slow, the confirmation will only be seen by the CPU on the corresponding valid_div phase.

The module contains several key control logics. First, repeated_access optimization: If the current internal request address biu_adr_i is the same as the last accessed wb_adr_o, then repeated_access=1. For continuous repeated reads, repeated_access_ack synchronized to the RISC domain will be pulled high in the cycle when repeated access is detected, and biu_dat_o will directly return the previously cached wb_dat_r, thereby avoiding repeated external bus accesses to the same address. Second, retry processing: If OR1200_WB_RETRY is defined, retry_cntr will be loaded after receiving wb_rty_i, and retry=1 will be maintained while the counter is non-zero, thereby temporarily preventing new cyc/stb from being issued. Third, graceful abort: When the external wb_stb_o has been issued but the internal biu_cyc_i/biu_stb_i has been canceled early, and no ack/err has been returned in the current beat, aborted is set and maintained in the WISHBONE field through aborted_r until the issued external transaction is finally officially ended by ack/err. This can avoid the interface being left hanging when the request has been abandoned internally but has not been completed externally.

The generation of wb_cyc_o and wb_stb_o reflects these priorities: normally driven by biu_cyc_i/biu_stb_i, but suspended if retry is valid; if an aborted transaction is being extended, continued until external termination even if the internal request has been revoked. wb_we_o in registered output mode also maintains the previous write direction during aborted expansion. previous_complete is used to record whether the last external access has been completed, which is the prerequisite for repeated_access judgment. In the optional WISHBONE B3 support, burst_len counts how many beats are left in the 4-beat wrap burst on wb_clk_i, wb_cti_o outputs the incrementing burst or end-of-burst depending on whether it is in a burst, and wb_bte_o is fixed to 4-beat wrap encoding.

Therefore, this module is not only a simple bus signal renaming bridge, but also implements cross-frequency confirmation synchronization, repeated access fast return, retry pause and graceful termination of issued transactions, ensuring that the internal request semantics of the CPU can be correctly mapped to the external WISHBONE bus.

Module name:
module or1200_iwb_biu(
    // RISC clock, reset and clock control
    input clk,
    input rst,
    input [1:0] clmode,

    // WISHBONE interface
    input wb_clk_i,
    input wb_rst_i,
    input wb_ack_i,
    input wb_err_i,
    input wb_rty_i,
    input [31:0] wb_dat_i,
    output wb_cyc_o,
    output [31:0] wb_adr_o,
    output wb_stb_o,
    output wb_we_o,
    output [3:0] wb_sel_o,
    output [31:0] wb_dat_o,
`ifdef OR1200_WB_CAB
    output wb_cab_o,
`endif
`ifdef OR1200_WB_B3
    output [2:0] wb_cti_o,
    output [1:0] wb_bte_o,
`endif

    // Internal RISC bus
    input [31:0] biu_dat_i,
    input [31:0] biu_adr_i,
    input biu_cyc_i,
    input biu_stb_i,
    input biu_we_i,
    input [3:0] biu_sel_i,
    input biu_cab_i,
    output [31:0] biu_dat_o,
    output biu_ack_o,
    output biu_err_o
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - clmode[1:0]: Clock-division mode that defines the WB-to-RISC timing ratio.
    - wb_clk_i: Wishbone-side clock input used by the external bus domain.
    - wb_rst_i: Wishbone-side reset input used by the external bus domain.
    - wb_ack_i: Acknowledge/transfer-complete indication for the external Wishbone bus.
    - wb_err_i: Error termination indication for the external Wishbone bus.
    - wb_rty_i: Retry/wait indication for the external Wishbone bus.
    - wb_dat_i[31:0]: Data bus for the external Wishbone bus.
    - biu_dat_i[31:0]: Data bus for the internal BIU interface.
    - biu_adr_i[31:0]: Address bus for the internal BIU interface.
    - biu_cyc_i: Cycle-valid request for the internal BIU interface.
    - biu_stb_i: Strobe/request-valid qualifier for the internal BIU interface.
    - biu_we_i: Write-enable / write-versus-read qualifier for the internal BIU interface.
    - biu_cab_i: Consecutive-address burst indication for the internal BIU interface.
    - biu_sel_i[3:0]: Byte-lane select for the internal BIU interface.
Output port:
    - wb_cyc_o: Cycle-valid request for the external Wishbone bus.
    - wb_adr_o[31:0]: Address bus for the external Wishbone bus.
    - wb_stb_o: Strobe/request-valid qualifier for the external Wishbone bus.
    - wb_we_o: Write-enable / write-versus-read qualifier for the external Wishbone bus.
    - wb_sel_o[3:0]: Byte-lane select for the external Wishbone bus.
    - wb_dat_o[31:0]: Data bus for the external Wishbone bus.
    - wb_cab_o: Consecutive-address burst indication for the external Wishbone bus. Present only when `OR1200_WB_CAB` is enabled.
    - wb_cti_o[2:0]: Cycle-type identifier for the external Wishbone bus. Present only when `OR1200_WB_B3` is enabled.
    - wb_bte_o[1:0]: Burst-type extension for the external Wishbone bus. Present only when `OR1200_WB_B3` is enabled.
    - biu_dat_o[31:0]: Data bus for the internal BIU interface.
    - biu_ack_o: Acknowledge/transfer-complete indication for the internal BIU interface.
    - biu_err_o: Error termination indication for the internal BIU interface.

    reg long_err_o: Long error output flag.

    wire long_ack_o: Long acknowledge output flag.
