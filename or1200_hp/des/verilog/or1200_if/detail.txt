
1. Saved-instruction mechanism
The module contains three state elements:
- saved: indicates a fetched instruction/address pair has been captured because the stage was frozen at the moment of acknowledgment;
- insn_saved: saved instruction word;
- addr_saved: saved PC.
This mechanism is essential. Without it, an acknowledged instruction could be lost if the pipeline freezes on the same cycle that the instruction arrives.

2. Instruction output selection
The output if_insn follows a priority scheme:
1. If icpu_err_i is high, or no_more_dslot is asserted, or rfe is asserted, output a NOP instruction pattern.
2. Else if saved is high, output insn_saved.
3. Else if icpu_ack_i is high, output the just-returned icpu_dat_i.
4. Else output a default NOP pattern.
Thus the stage never exposes random data when no valid fetch has completed.

3. PC output selection
if_pc is addr_saved when saved is high; otherwise it is the current icpu_adr_i. That guarantees the instruction and PC stay paired when a fetched instruction is buffered.

4. Stall and refetch generation
- if_stall is asserted when there is no error, no acknowledge, and no saved instruction.
- genpc_refetch is asserted when a saved instruction exists and a new acknowledge also arrives.
This tells the PC generation logic that the bus/cache returned a word while a previous word was buffered, so the address may need to be reissued or preserved.

5. Exception decoding
The module decodes icpu_err_i together with icpu_tag_i into specific exceptions:
- ITLB miss when tag == OR1200_ITAG_TE
- IMMU fault when tag == OR1200_ITAG_PE
- instruction bus error when tag == OR1200_ITAG_BE
These exceptions are suppressed when no_more_dslot is asserted.

6. Sequential behavior
6.1 saved flag
- reset or flushpipe clears saved;
- if an instruction is acknowledged while if_freeze is asserted and saved is not already set, saved becomes 1;
- when if_freeze is released, saved clears.

6.2 insn_saved register
- reset and flushpipe load a NOP constant;
- when an acknowledged instruction arrives during freeze and saved is not yet set, insn_saved captures icpu_dat_i;
- when the stage is not frozen, insn_saved returns to the NOP constant.

6.3 addr_saved register
- reset and flushpipe clear it;
- when an acknowledged instruction arrives during freeze and saved is not yet set, it captures icpu_adr_i;
- when not frozen, it tracks icpu_adr_i.

7. Summary
or1200_if.v is the fetch-stage acceptance buffer. It classifies fetch errors, inserts NOPs under special control-flow conditions, and preserves one outstanding instruction/PC pair across pipeline freezes.
