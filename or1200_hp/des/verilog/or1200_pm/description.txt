
Module `or1200_pm` implements power-management control registers and generates low-power mode control outputs.

This module implements power management according to the OR1K architectural specification. It stores power-mode control bits, generates clock-gating outputs for major processor subsystems, exposes a programmable clock slowdown field, and produces wakeup and low-voltage indications.

Description:



This module implements the power management unit (PM), which is responsible for saving the software programmable state of the power management register PMR, and accordingly outputs the clock deceleration coefficient, clock gating requests of multiple sub-modules, wake-up indications, and low-voltage requests. It does not actually perform clock gating or voltage regulation, but rather outputs control signals for use by the external clock/power infrastructure.

When `OR1200_PM_IMPLEMENTED` is enabled, the module contains the 4-bit slow clock divider `sdf`, doze mode enable `dme`, sleep mode enable `sme` and dynamic clock gating enable `dcge`. These registers are updated on the rising edge of `clk` with an asynchronous high reset of `rst`. After reset, all four are cleared to zero, indicating normal working mode. If the PMR is hit via SPR access and `spr_write` is valid, the above fields are loaded from `spr_dat_i`. In addition, if the external `pic_wakeup` is pulled high, the module will automatically clear `dme` and `sme`, thereby restoring the processor from a low-power state; `dcge` and `sdf` will not be cleared by `pic_wakeup`.

In terms of the read interface, when the read register configuration is supported, the `spr_dat_o` combination returns the current field value of the PMR, in which the unused bits are cleared according to the configuration. Address decoding `pmr_sel` can be decoded by the full address or just the group number, depending on the macro definition. The module contains no explicit state machine; behavior is fully determined by PMR fields and pic_wakeup, so the PM behavior is completely determined by the current bits of the PMR and external wake-up conditions.

The output control semantics are clear as follows: `pm_clksd` is directly equal to `sdf`; `pm_cpu_gate` is set when `(dme | sme) & ~pic_wakeup`, indicating that the CPU main clock should be gated; the gated outputs of data Cache, instruction Cache, DMMU and IMMU all directly follow `pm_cpu_gate`; the gate control of Tick Timer is more strict, only when `sme & ~pic_wakeup` is set, that is, TT is allowed to be turned off only in sleep mode. `pm_wakeup` is directly equivalent to `pic_wakeup` and is used as a global wakeup signal for degating. `pm_lvolt` is set when `pm_cpu_gate` or external `pm_cpustall` is valid, indicating that the system can enter a lower operating voltage.

Reset has highest priority; software writes to PMR take precedence over pic_wakeup, since the pic_wakeup clearing of dme/sme is in a lower-priority else if branch. In the combined output, `pic_wakeup` has a direct coverage effect on each gate signal, because once wake-up occurs, the gating conditions require `~pic_wakeup` to be true. If PM is not enabled, the implementation degrades to normally open: all gating and deceleration are 0, `pm_wakeup` is fixed to 1, `pm_lvolt` is 0, and the SPR read port returns all zeros.

module or1200_pm(
    // RISC Internal Interface
    input clk,
    input rst,
    input pic_wakeup,
    input spr_write,
    input [31:0] spr_addr,
    input [31:0] spr_dat_i,
    output [31:0] spr_dat_o,

    // Power Management Interface
    output [3:0] pm_clksd,
    input pm_cpustall,
    output pm_dc_gate,
    output pm_ic_gate,
    output pm_dmmu_gate,
    output pm_immu_gate,
    output pm_tt_gate,
    output pm_cpu_gate,
    output pm_wakeup,
    output pm_lvolt
);

Input ports:
    - clk: Primary clock; sequential state in this module updates on its rising edge.
    - rst: Reset input that returns local state elements to their defined reset values.
    - pic_wakeup: Programmable interrupt controller wakeup.
    - spr_write: SPR write strobe for this module.
    - spr_addr[31:0]: SPR address used for register decode.
    - spr_dat_i[31:0]: Write data from the SPR/control path.
    - pm_cpustall: CPU-stall indication used by the power-management block.
Output port:
    - spr_dat_o[31:0]: Read data returned on the SPR bus.
    - pm_clksd[3:0]: Programmable clock-slowdown factor generated by the power-management logic.
    - pm_dc_gate: Data-cache clock-gate request.
    - pm_ic_gate: Instruction-cache clock-gate request.
    - pm_dmmu_gate: DMMU clock-gate request.
    - pm_immu_gate: IMMU clock-gate request.
    - pm_tt_gate: Tick-timer clock-gate request.
    - pm_cpu_gate: CPU clock-gate request.
    - pm_wakeup: Wakeup indication generated by the PM block.
    - pm_lvolt: Low-voltage request generated by the PM block.
Internal reg/wire signals:
    reg [3:0] sdf: Clock slow-down factor from the PM register.
    reg dme: Doze-mode enable bit.
    reg sme: Sleep-mode enable bit.
    reg dcge: Dynamic clock-gating enable bit.
    wire pmr_sel: Power-management register select.
