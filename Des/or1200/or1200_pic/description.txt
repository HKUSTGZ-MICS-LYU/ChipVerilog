or1200_pic implements the programmable interrupt controller logic for the OR1200 processor. The module receives a 20-bit external interrupt input vector pic_int[19:0], masks interrupts according to the compile-time configuration, optionally latches interrupt status, and provides SPR access to PIC-related registers. It finally outputs a consolidated processor interrupt request intr and a power-management wakeup signal pic_wakeup.

When OR1200_PIC_IMPLEMENTED is defined, the main PIC logic is enabled. In this configuration, whether picmr[19:2] and picsr[19:0] are real registers is controlled by separate macros. If OR1200_PIC_PICMR is defined, picmr[19:2] is declared as a reg and serves as the programmable interrupt mask register. If this macro is not defined, picmr[19:2] is declared as a wire and is assigned a fixed all-ones mask value, with no writable storage. If OR1200_PIC_PICSR is defined, picsr[19:0] is declared as a reg and serves as the interrupt status register. If this macro is not defined, picsr[19:0] is declared as a wire and directly equals the external interrupt input pic_int, with no pending-status latch behavior.

When OR1200_PIC_PICMR is defined, picmr[19:2] is updated on the rising edge of clk and reset by the active-high asynchronous reset rst. On reset, picmr is initialized to {1'b1, {OR1200_PIC_INTS-3{1'b0}}}. For the 20-bit interrupt input used by this module, this means picmr[19]is reset to 1 andpicmr[18:2]is reset to 0. Software can modify this register through an SPR write. Whenspr_csis asserted,spr_addr[1:0]matches the PICMR offset, andspr_writeis asserted,picmr[19:2]is written withspr_dat_i[19:2]`.

The module generates the current unmasked interrupt vector using um_ints = pic_int & {picmr, 2'b11}. Since picmr only contains bits [19:2], the lowest two mask bits are not stored in the register. Instead, they are forced to 2'b11 when the effective mask vector is formed. Therefore, pic_int[0] and pic_int[1] are always unmaskable. Whether pic_int[19:2] are enabled depends on the value of picmr[19:2]. If OR1200_PIC_PICMR is not defined, picmr is a fixed all-ones value, so all implemented interrupt bits are effectively unmasked.

When OR1200_PIC_PICSR is defined, picsr[19:0] is updated on the rising edge of clk and cleared by the active-high asynchronous reset rst. During normal operation, picsr performs picsr <= picsr | um_ints, continuously latching currently active unmasked interrupts. When software writes to PICSR through the SPR interface, and spr_cs is asserted, spr_addr[1:0] matches the PICSR offset, and spr_write is asserted, the next value of picsr becomes spr_dat_i[19:0] | um_ints. Therefore, a software write can modify or clear status bits, but any interrupt bit that is still currently active and unmasked is set again in the same clock update.

The PICMR and PICSR write-select signals are generated by combinational decoding of spr_cs and spr_addr[1:0]. picmr_sel is asserted when spr_cs is asserted and the two low address bits equal OR1200_PIC_OFS_PICMR. picsr_sel is asserted when spr_cs is asserted and the two low address bits equal OR1200_PIC_OFS_PICSR. These two select signals are used only for register write control.

The SPR read-data path is combinational. In the OR1200_PIC_IMPLEMENTED branch, spr_dat_o is declared as a reg used by combinational logic, and its value is generated from spr_addr[1:0], picmr, and picsr. This read path itself does not check spr_cs. When OR1200_PIC_READREGS is defined and the read address corresponds to PICMR, spr_dat_o[19:0] returns {picmr, 2'b0}. The lowest two bits read as 0 because they are not actual storage bits in PICMR, even though they are forced to 1 during interrupt mask calculation. In the default read branch, spr_dat_o[19:0] returns picsr[19:0]. If OR1200_PIC_READREGS is not defined, the dedicated PICMR read branch is not compiled, and the read logic returns picsr through the default case.

When OR1200_PIC_UNUSED_ZERO is defined, the unused bits of spr_dat_o above the actual interrupt width are explicitly cleared. For a 20-bit interrupt input, spr_dat_o[31:20] is set to 0. If OR1200_PIC_UNUSED_ZERO is not defined, the combinational read logic in the code does not explicitly assign these upper bits, so their values are not fully specified by this logic.

The interrupt request output intr is generated by a reduction OR of the current unmasked interrupt vector, namely intr = |um_ints. Therefore, intr is asserted whenever at least one external interrupt input is currently active and unmasked. This signal is only a consolidated interrupt-request flag. It does not contain an interrupt number and does not implement priority encoding. Interrupt priority selection or exception-entry handling is performed outside this module.

pic_wakeup is directly equal to intr. Therefore, whenever any currently active and unmasked interrupt request arrives, the module asserts both the CPU interrupt request and the wakeup request to the power-management logic.

When OR1200_PIC_IMPLEMENTED is not defined, the module degenerates into the simplest interrupt mode. In this configuration, there is no programmable mask register and no interrupt status register. intr is generated only from the two lowest external interrupt inputs, as intr = pic_int[1] | pic_int[0], and pic_wakeup still directly follows intr. In this branch, if OR1200_PIC_READREGS is defined, the implemented interrupt field of the SPR read data is assigned 0. If OR1200_PIC_UNUSED_ZERO is also defined, the unused upper bits are also cleared. Otherwise, this non-implemented branch does not fully and explicitly drive the SPR read-data output.

module or1200_pic(
    // RISC Internal Interface
    input clk,
    input rst,
    input spr_cs,
    input spr_write,
    input [31:0] spr_addr,
    input [31:0] spr_dat_i,
    output [31:0] spr_dat_o,
    output pic_wakeup,
    output intr,

    // PIC Interface
    input [19:0] pic_int
);

Input ports:
    clk: Primary clock. Sequential PIC state, when implemented, updates on the rising edge of this clock.
    rst: Asynchronous active-high reset for implemented PIC state registers.
    spr_cs: SPR chip-select used in PICMR and PICSR write-address decoding.
    spr_write: SPR write strobe.
    spr_addr[31:0]: SPR address. This module decodes spr_addr[1:0] to select PICMR or PICSR.
    spr_dat_i[31:0]: SPR write data. Bits [19:2] are used for PICMR writes, and bits [19:0] are used for PICSR writes.
    pic_int[19:0]: External interrupt input vector.

Output port:
    spr_dat_o[31:0]: SPR read-data output. Depending on macro configuration and address, it returns PICMR, PICSR, or zero in the non-implemented read-register case.
    pic_wakeup: Wakeup request to the power-management logic. It is asserted whenever intr is asserted.
    intr: Consolidated interrupt request to the CPU. It is asserted when at least one currently active interrupt is unmasked.

Internal reg/wire signals:
    picmr[19:2]: PIC mask value. It is a reg when OR1200_PIC_PICMR is defined, and a wire driven by a constant mask value when OR1200_PIC_PICMR is not defined.
    picsr[19:0]: PIC status value. It is a reg when OR1200_PIC_PICSR is defined, and a wire directly assigned from pic_int when OR1200_PIC_PICSR is not defined.
    picmr_sel: PICMR write-select signal, decoded from spr_cs and spr_addr[1:0].
    picsr_sel: PICSR write-select signal, decoded from spr_cs and spr_addr[1:0].
    um_ints[19:0]: Current unmasked interrupt vector, computed as pic_int & {picmr, 2'b11}.
    spr_dat_o[31:0]: In the implemented-PIC branch, this is declared as a combinational reg used to drive the SPR read-data output.

Processing Flow

When OR1200_PIC_IMPLEMENTED is defined, the module first determines the effective interrupt mask. If OR1200_PIC_PICMR is defined, the mask value comes from the programmable register picmr[19:2]; otherwise, picmr[19:2] is a fixed all-ones wire value. The two lowest mask bits are always forced to 1 by forming {picmr, 2'b11}, so interrupt inputs pic_int[0] and pic_int[1] are always unmasked.

The external interrupt vector pic_int[19:0] is then ANDed with the effective mask to produce the current unmasked interrupt vector um_ints. This vector represents only the interrupt inputs that are currently active and allowed through the mask.

If OR1200_PIC_PICSR is defined, um_ints is ORed into the status register picsr on each clock edge, so active unmasked interrupts are latched as pending status. If software writes to PICSR in the same cycle, the written value is also ORed with um_ints, meaning currently active unmasked interrupts remain set. If OR1200_PIC_PICSR is not defined, no pending status is latched and picsr directly reflects pic_int.

In parallel, the module generates the processor interrupt request by reducing um_ints with OR logic. If any bit of um_ints is 1, intr is asserted. The wakeup request pic_wakeup is directly assigned from intr, so the same condition that requests an interrupt from the CPU also requests wakeup from the power-management logic.

SPR write accesses are decoded using spr_cs, spr_write, and spr_addr[1:0]. A write to the PICMR offset updates picmr[19:2] only when the programmable PICMR register is implemented. A write to the PICSR offset updates picsr[19:0] only when the programmable PICSR register is implemented.

SPR read access is handled by combinational logic based on spr_addr[1:0]. When PICMR readback is enabled by OR1200_PIC_READREGS, the PICMR offset returns {picmr, 2'b0} in the low 20 bits. Other read cases return picsr[19:0]. If OR1200_PIC_UNUSED_ZERO is defined, unused upper bits of spr_dat_o are cleared to zero.

When OR1200_PIC_IMPLEMENTED is not defined, the programmable processing path is bypassed. The module directly generates intr from pic_int[1] | pic_int[0], assigns pic_wakeup = intr, and provides only the limited read-data behavior enabled by the read-related macros.
