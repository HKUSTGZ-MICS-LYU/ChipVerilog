## 2. 功能需求（必须）

- SHALL: 必须满足 I2C 基本时序：SDA 仅在 SCL 低电平阶段切换，SCL 高电平阶段保持稳定（START/STOP 条件除外）。

- SHALL: 与 Wishbone 侧交互时，必须保证 `ack` 返回时序可预测且寄存器读写原子一致。

## 7. PDF 依据摘要（已提炼）
- A transition on the SDA line while SCL is high is interpreted as a command (see START and STOP signals).
- If the master, as the receiving device, does not acknowledge the slave, the slave releases the SDA line for the master to generate a STOP or Repeated START signal.
- 5.3 Bit Command Controller The Bit Command Controller handles the actual transmission of data and the generation of the specific levels for START, Repeated START, and STOP signals by controlling the SCL and SDA lines.
- If the slave signals a No Acknowledge, the master can generate a STOP signal to abort the data transfer or generate a Repeated START signal and start a new transfer cycle.
