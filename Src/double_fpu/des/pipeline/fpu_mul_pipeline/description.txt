Functional Overview:
Module `fpu_mul` computes double-precision floating-point multiplication by forming the significand product, adjusting exponent/sign, and normalizing the result path.

Module name:
    fpu_mul

Input ports:
    input clk: Clock signal that defines sequential update timing for this logic.
    input rst: Reset signal that initializes state elements to known values.
    input enable: Active-high pipeline enable; all state updates occur only when asserted.
    input [1:0] rmode: IEEE-754 rounding mode: 2'b00=nearest, 2'b01=zero, 2'b10=+inf, 2'b11=-inf.
    input [63:0] opa, opb: IEEE-754 double-precision input operands.

Output port:
    output ready: Asserted when the fixed-latency pipeline completes and the result is valid.
    output [63:0] outfp: Final IEEE-754 multiplication result after normalization and rounding.

Implementation:
- The module computes double-precision floating-point multiplication by forming the significand product, adjusting exponent/sign, and normalizing the result path.
- Rounding is applied based on guard and remainder bits of the product.
- The mul_a and mul_b are 53-bit values storing the mantissa with implicit leading 1 for normalized inputs.
