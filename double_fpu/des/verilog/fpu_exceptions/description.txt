Functional Overview:
Module `fpu_exceptions` generates IEEE-754 exception flags such as invalid, overflow, underflow, divide-by-zero, and inexact conditions.
This source file implements special-case handling and status-flag generation for the floating-point unit. It checks for NaNs, infinities, divide-by-zero, invalid arithmetic combinations, overflow, underflow, and inexact results. It can override the rounded datapath result with a special IEEE-754 output and drives the final exception-related status signals.
This module performs all special-case substitution and status-flag generation for the floating-point unit. It receives the rounded normal datapath result, the original operands, the original opcode, the post-round exponent, and the low two remainder bits. It decides whether the normal rounded result should be overridden by NaN, infinity, max-finite, or signed-zero, and it generates underflow, overflow, inexact, exception, and invalid flags.

Main function
-------------
The exception block operates after the arithmetic and rounding stages. It receives:
- the original operands
- the rounded candidate result
- the post-round exponent
- the two low-order remainder bits from the arithmetic path
- the operation code
- the rounding mode

It decides whether the rounded datapath result can pass through unchanged or whether a special result such as NaN, infinity, largest finite number, or zero must be returned instead.

Description:
This module handles all special cases and exception conditions for the floating-point unit. Its inputs include the original operands opa and opb, the normal rounded result in_except, the extended exponent exponent_in, the two rounding-related extra bits mantissa_in, the operation code fpu_op, and the rounding mode rmode. Its outputs are the final result out, the exception override enable ex_enable, and the five status flags underflow, overflow, inexact, exception, and invalid.

The exceptions module checks all of the special cases listed in the documentation, including divide by zero, 0/0, infinity/infinity, divide by infinity, 0 * infinity, arithmetic overflow, arithmetic underflow, +infinity + (-infinity), +infinity - +infinity, -infinity - -infinity, QNaN input, and SNaN input. When any of these cases occurs, the module generates the appropriate special output and asserts the required flags. If either input is a QNaN, the output is a QNaN. If either input is an SNaN, the output is converted to a QNaN and invalid is asserted. For other invalid operations such as 0/0, infinity/infinity, 0 * infinity, or invalid infinity add/subtract combinations, the output is NaN and invalid is asserted .

The module also controls the final representation of overflow and underflow results. If the arithmetic result overflows, the default output is positive or negative infinity and overflow is asserted. However, if the rounding mode requires infinity to be rounded down to the largest finite number, the module outputs the largest positive or negative finite value instead of infinity. Specifically, if the result is positive infinity and the rounding mode is round to zero or round to negative infinity, the output becomes the largest positive number; if the result is negative infinity and the rounding mode is round to zero or round to positive infinity, the output becomes the largest negative number. The document explicitly states that this infinity rounding behavior is performed in the exceptions module, not in the rounding module .

For underflow, the module forces the result to signed zero when the appropriate conditions exist and asserts underflow. For inexact, the flag is asserted if either of the two extra remainder bits is 1, or if the result is modified due to overflow or underflow. The exception output is a summary flag that is asserted whenever any exception condition occurs. If the module determines that the normal rounded result must be overridden, it asserts ex_enable, and the top level selects this module’s out as the final output.

All detections, flags, and outputs are registered on the rising edge of the clock. Reset clears all flags and outputs. This module is the final authority for special-value propagation, invalid-operation handling, infinity replacement, and exception reporting in the FPU.
