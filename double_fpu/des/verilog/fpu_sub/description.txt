Module `fpu_sub` implements double-precision floating-point subtraction using operand magnitude ordering, alignment shifting, significand subtraction, leading-zero normalization, and denormal boundary adjustment.
This module performs the aligned mantissa subtraction stage for double-precision floating-point operations whose effective arithmetic is subtraction. It produces an intermediate sign, 11-bit exponent, and 56-bit mantissa bundle for later rounding and exception handling.
fpu_sub.v compares operand magnitudes, selects the larger magnitude as the minuend, aligns the smaller operand to the larger exponent, preserves sticky information when alignment discards all lower bits, subtracts the significands, counts leading zeros to renormalize the difference, handles exact zero and denormal underflow cases, computes the final sign, and produces an intermediate result for rounding and exception processing.
The implementation is a single clocked always block using nonblocking assignments throughout, together with a separate combinational always block that implements the leading-zero priority encoder. The clocked block forms a multi-cycle pipeline: each signal reads from the previous cycle's registered state and writes into registers that are read by subsequent cycles.
 
Main function
-------------
The module supports two logical use cases:
- true subtraction, when the effective operation is A - B with same-sign operands
- sign-converted addition cases, when the top level redirects opposite-sign addition into the subtraction datapath
 
To keep the arithmetic simple, the module always subtracts the smaller magnitude from the larger magnitude and then derives the final sign according to which operand had greater magnitude and which logical operation is being performed.
 
Description:
This module performs the floating-point subtraction datapath for double-precision operands. It is used for same-sign subtraction and also for cases that the top level converts from opposite-sign addition into a magnitude subtraction. The outputs are the intermediate result sign, normalized 11-bit exponent exponent_2, and 56-bit extended mantissa diff_2, which is passed to the rounding stage rather than directly encoded as the final IEEE-754 result.
The module always subtracts the smaller magnitude from the larger magnitude. If A is smaller than B, the hardware computes B - A and then adjusts the sign so that the final result is mathematically correct.
As in addition, the operands are aligned before subtraction. The smaller-exponent mantissa is right-shifted so both operands are represented at the same exponent. The effective exponent difference used for alignment is exponent_large - exponent_small - large_norm_small_denorm, where large_norm_small_denorm corrects for the implicit-1 gap when the large operand is normalized and the small operand is denormalized. Normalized numbers include the hidden leading 1; denormalized numbers do not.
Sticky information is preserved through the subtra_fraction_enable mechanism: if the small operand is nonzero but its aligned shift result is all zero, the design forces the low bit of subtra_shift_3 to 1 rather than using the zero-valued shift result.
After subtraction, the difference is stored in diff, and a combinational priority-encoder casex block counts leading zeros and produces diff_shift (values 0-54 for each leading-one position; 55 if diff is all zero). The result is then left-shifted by diff_shift_2 (the registered copy of diff_shift), and the exponent is reduced by the same amount, thereby normalizing the output. If the shift amount would drive the exponent negative, the exponent is clamped to zero and the shift is limited to exponent_large. If diff is exactly zero, exponent_2 is forced to zero. If a normalized input pair produces a denormal result (in_norm_out_denorm), diff_1 is right-shifted one additional bit before being placed into diff_2.
All outputs update on the rising edge of the clock, and reset clears all internal registers. NaN, infinity, and invalid-operation cases are not resolved here; they are handled by the exceptions stage.
module fpu_sub( clk, rst, enable, opa, opb, fpu_op, sign, diff_2, exponent_2);
 
Input ports:
    input clk: Rising-edge clock. All register updates in the clocked always block occur on the positive edge of this signal.
    input rst: Synchronous active-high reset. When asserted, all internal pipeline registers and output registers are cleared to zero on the next rising clock edge.
    input enable: Active-high pipeline enable. All assignments inside the clocked always block are gated by this signal; when deasserted, the pipeline holds its current state.
    input [63:0] opa: First IEEE-754 double-precision floating-point operand. Bit 63 is the sign, bits 62:52 are the biased exponent, and bits 51:0 are the mantissa fraction field.
    input [63:0] opb: Second IEEE-754 double-precision floating-point operand. Same field layout as opa.
    input [2:0] fpu_op: Original top-level opcode passed down from fpu_double. Used in sign selection: the subtract module is invoked both for true subtraction requests and for addition requests whose operands have opposite signs, and the sign correction formula differs between the two cases. Specifically, fpu_op == 3'b000 identifies the routed-addition case.
 
Output ports:
    output reg sign: Result sign bit. If operand A has greater-or-equal magnitude, sign = opa[63]. Otherwise, sign = (!opb[63]) XOR (fpu_op == 3'b000). This accounts for both the true subtraction case and the routed opposite-sign addition case.
    output reg [55:0] diff_2: Intermediate 56-bit mantissa bundle forwarded to the rounding stage. Bit 55 is a reserved leading zero. Bits 54:0 hold the normalized or denormalized subtraction result, including two low-order remainder bits for rounding. Bit 54 is the leading integer position for normalized results; bits 53:2 are the 52-bit mantissa candidate; bits 1:0 carry low remainder and sticky information.
    output reg [10:0] exponent_2: Intermediate 11-bit exponent after renormalization, clamped to zero for exact cancellation. Forwarded to the rounding stage.
 
Internal reg/wire signals:
    reg [6:0] diff_shift: Leading-zero count of diff, produced combinationally by the casex priority encoder. Values 0-54 indicate the position of the leading 1; value 55 indicates diff is all zero.
    reg [6:0] diff_shift_2: Registered copy of diff_shift; one pipeline stage delayed, used in the renormalization shift and exponent update.
    reg [10:0] exponent_a: Biased exponent field extracted from opa[62:52].
    reg [10:0] exponent_b: Biased exponent field extracted from opb[62:52].
    reg [51:0] mantissa_a: Mantissa fraction field extracted from opa[51:0].
    reg [51:0] mantissa_b: Mantissa fraction field extracted from opb[51:0].
    reg expa_gt_expb: 1 if exponent_a > exponent_b.
    reg expa_et_expb: 1 if exponent_a == exponent_b.
    reg mana_gtet_manb: 1 if mantissa_a >= mantissa_b.
    reg a_gtet_b: 1 if operand A has greater-or-equal magnitude; computed as expa_gt_expb | (expa_et_expb & mana_gtet_manb).
    reg sign: Registered output port (also used as internal pipeline register). Holds the result sign bit.
    reg [10:0] exponent_small: Biased exponent of the smaller-magnitude operand.
    reg [10:0] exponent_large: Biased exponent of the larger-magnitude operand.
    reg [51:0] mantissa_small: Mantissa fraction of the smaller-magnitude operand.
    reg [51:0] mantissa_large: Mantissa fraction of the larger-magnitude operand.
    reg small_is_denorm: 1 if the smaller-magnitude operand is denormalized (exponent_small == 0).
    reg large_is_denorm: 1 if the larger-magnitude operand is denormalized (exponent_large == 0).
    reg large_norm_small_denorm: 1 when the large operand is normalized and the small operand is denormalized; used to adjust the effective exponent difference by 1 to account for the implicit-1 gap.
    reg small_is_nonzero: 1 if (exponent_small > 0) or any bit of mantissa_small is 1; used in subtra_fraction_enable.
    reg [10:0] exponent_diff: Effective alignment shift amount: exponent_large - exponent_small - large_norm_small_denorm.
    reg [54:0] minuend: 55-bit extended mantissa of the larger operand: {!large_is_denorm, mantissa_large, 2'b00}.
    reg [54:0] subtrahend: 55-bit extended mantissa of the smaller operand: {!small_is_denorm, mantissa_small, 2'b00}.
    reg [54:0] subtra_shift: Result of right-shifting subtrahend by exponent_diff to align to the larger exponent.
    wire subtra_shift_nonzero = |subtra_shift[54:0]: 1 if any bit of subtra_shift is nonzero after alignment.
    wire subtra_fraction_enable = small_is_nonzero & !subtra_shift_nonzero: Asserted when the small operand is nonzero but all its bits were shifted out; triggers injection of a low-order sticky bit.
    wire [54:0] subtra_shift_2 = { 54'b0, 1'b1 }: Constant used to inject a sticky guard bit when subtra_fraction_enable is asserted. This is a fixed constant, not a pipeline register.
    reg [54:0] subtra_shift_3: Final subtrahend value used in subtraction; equals subtra_shift_2 when subtra_fraction_enable is asserted, otherwise equals subtra_shift.
    reg [54:0] diff: Raw difference: minuend - subtra_shift_3.
    reg diffshift_gt_exponent: 1 if diff_shift_2 > exponent_large; indicates that renormalization would drive the exponent negative, requiring clamping.
    reg diffshift_et_55: 1 if diff_shift_2 == 55; indicates that diff was exactly zero, so exponent_2 must be forced to zero.
    reg [54:0] diff_1: Left-shifted and normalized difference. If diffshift_gt_exponent, diff_1 = diff << exponent_large; otherwise diff_1 = diff << diff_shift_2.
    reg [10:0] exponent: Intermediate exponent after renormalization. If diffshift_gt_exponent, exponent = 0; otherwise exponent = exponent_large - diff_shift_2.
    reg [10:0] exponent_2: Registered output port (also used as internal pipeline register). If diffshift_et_55, exponent_2 = 0; otherwise exponent_2 = exponent.
    wire in_norm_out_denorm = (exponent_large > 0) & (exponent == 0): Asserted when a normalized input pair produces a denormal result; causes diff_1 to be right-shifted one additional bit in the output bundle.
    reg [55:0] diff_2: Registered output port (also used as internal pipeline register). If in_norm_out_denorm, diff_2 = {1'b0, diff_1 >> 1}; otherwise diff_2 = {1'b0, diff_1}.
